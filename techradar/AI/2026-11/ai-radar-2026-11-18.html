Co-Designing Sparse Attention for Efficient Long-Context Inference

Sparse attention moves the cost of attention to an indexer, which requires optimizing the indexer and Top-k selection for efficient GPU inference. Key design choices involve balancing compute and memory by controlling parameters like group size ($G$), head dimension ($H_{sz}$), and compression ratio ($CR$). Guidelines suggest using $KH=1$, $H_{sz}=128$ or $256$, and employing block-level selection for better key fetching. Fusing Top-k into the indexer and using speculative decoding further accelerate inference. Overall efficiency is achieved by reducing the number of keys scored through compression and sharing.

Finally, handling unmeasured confounding requires methods like difference-in-differences to account for stable, unobserved traits.
