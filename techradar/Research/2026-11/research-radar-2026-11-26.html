Irreducible Governance Structure for Autonomous Agent Systems: Fair Allocation, Strategy-Proofness, and Multi-Scale Composition

Allocation of resources is a structural component of agent governance, introducing trade-offs between fairness, efficiency, and strategy-proofness. Impossibility results demonstrate that these allocation constraints cannot be resolved in a single control layer. This necessitates a multi-scale governance structure involving temporal atomicity, state enforcement, behavioral monitoring, and population allocation. An irreducibility theorem states that no architecture can eliminate these dimensions without sacrificing correctness or stability. Ultimately, agent governance is reframed as a structural problem concerning how access to execution is determined.

MOZAIC: An Audio-Video Deepfake Benchmark for Telling What Is Fake

MOZAIC is a paired benchmark designed to measure the contribution of audio and video modalities to deepfake detection. It provides 137,745 clips with a four-way label indicating real/fake combinations for both video and audio. The benchmark covers deepfakes involving face swapping, video diffusion, and voice conversion. Evaluation showed that multimodal LLMs performed well, and detectors achieved high accuracy, though generalization remains an open question. The authors release the dataset, a smaller split, code, and prompts for further research.

Conservative Overlap Fuzzy Rough Sets for Incomplete Data

The Conservative Overlap Fuzzy Rough Set (COFRS) model is proposed to address attribute reduction in incomplete information systems where missing values complicate rough set theory. COFRS defines object similarity based on a weighted overlap of present attributes, penalizing missing values globally. This similarity is used to define a soft dependency degree via weighted granule consistency, and reducts are found using greedy backward elimination. Benchmarks show COFRS selects smaller reducts on average compared to other methods, emphasizing compactness over predictive accuracy.

Beyond Static Charts: Benchmarking Interactive Chart-to-Code Generation for MLLMs

Existing benchmarks for multimodal large language models (MLLMs) in chart-to-code generation primarily focus on static charts, ignoring interactive chart exploration. ChartInt, a new benchmark, was introduced to specifically evaluate interactive generation by including examples of common interaction patterns and editing tasks. A preset state snapshot protocol was developed to ensure reproducible evaluation of dynamic interaction behaviors. The evaluation framework measures both semantic and stylistic consistency in these interactive scenarios. Experiments demonstrate that MLLMs perform significantly worse on interactive tasks compared to static chart generation.

What People Choose Not to Say: A Multimodal Benchmark for Fine-Grained Information Manipulation in Conversations

Existing benchmarks for social understanding often focus on coarse-grained emotion or binary truth-deception, neglecting finer manipulation tactics in conversations. This paper introduces InfoCon, a multimodal benchmark designed to assess fine-grained information manipulation strategies such as withholding, leakage, fabrication, evasion, and defensive counterclaim. It allows for a systematic analysis of how multimodal models understand these nuanced manipulation tactics. Ultimately, the work provides a testing ground beyond simple truth-deception judgments for evaluating AI's conversational understanding.

Antares-Smaug: Adversarial Names, Tokens and Attack Rewrites: Sanitisers Miss Unseen Generalisations

Researchers attacked six Laya models using 81 programmatic edits and 566 synthetic items to test their robustness. Attacks leveraging adversarial names significantly influenced the released model's answers, with option naming steering results in 32% of cases. Sanitizers failed to capture these unseen generalizations, as freezing them reduced attack effectiveness by 72% but not fully preventing attacks. An attacker selecting the best strings restored success to 84%, demonstrating vulnerabilities in current defenses. The study indicates that existing sanitizers miss important attack vectors related to naming and character edits.

ContextLure: Exploiting Benign Conversation History for Indirect Prompt Injection

Attackers can exploit benign conversation history to perform indirect prompt injection attacks against LLMs. The ContextLure framework allows an attacker to silently observe and extract evidence from existing conversations. To effectively exploit this, the framework selects evidence based on user/system preferences and uses an urgency/priority matrix for crafting malicious requests. Experimental results showed attackers could leverage benign interaction evidence for later attacks with notable success rates. This demonstrates a vulnerability in agent interactions where prior context can be misused for malicious purposes.

Learning What vs. Learning How: Decomposing Task and Interface Competence in Agentic Training

Agentic competence is decomposed into task competence, the knowledge to solve a task, and interface competence, the ability to act on that knowledge via a specific harness. The study investigates how training methods, conditioned by these harness structures, affect the development of these two competencies. Multi-harness distillation aggregates task knowledge but requires preserving interface competence for the knowledge to be realized. Harness rehearsal, combining task supervision and interface exercise, yields significantly better results than either alone. Policy reinforcement learning proves more robust than distillation for single-harness training in maintaining interface competence.

SpatialCraft: Evolving Procedural Intelligence from Experience and Skills for Spatial Reasoning Agents

Spatial reasoning agents often struggle with orchestrating external tools like 3D reconstruction and segmentation. SpatialCraft is a self-evolving framework designed to improve the orchestration of these tools using experience and skills. It maintains "Experiences," distilled from contrasting rollouts, and "Skills," defined by explicit conditions. A Contrastive Utility Score is used to estimate the effect of experiences, consolidating positive ones into skills. The framework demonstrates that a frozen agent can learn effective spatial tool orchestration from its own interaction history.

Quantum Machine Learning for Signature Forgery Detection

This work explores quantum machine learning pipelines for offline signature forgery detection using public image data. It employs a ZZ feature map quantum kernel paired with classical learners like K-Nearest Neighbors and Support Vector Machine. A hybrid approach utilizes a frozen EfficientNetB0 for feature extraction followed by a quantum-compatible principal component projection. This hybrid method achieved 92.62% accuracy on a held-out test fold and 91.26% mean accuracy across five-fold cross-validation. The proposed pipeline maintains a quantum embedding step suitable for NISQ hardware.

Temporal Exposure to Byzantine Vulnerability Under Intermittent Participation in Federated Learning

Dynamic Participation Exposure (DPE) is introduced to study Byzantine vulnerability when client participation varies in Federated Learning. Intermittent participation transforms Byzantine robustness from a static property into a stochastic and temporal one. The study analyzes the probability of per-round exposure based on the active-set size and examines the accumulation of exposure over multiple rounds. Intermittent participation alone does not guarantee aggregation failure, but it necessitates new mitigation strategies. Actionable recommendations include constraints on active sets, temporal monitoring, and adaptive aggregation techniques.

Geophysical inverse problems are ill-posed, making classical Bayesian methods computationally expensive. Deep Learning-Based Mesoscopic Emission Modeling

Existing emission models face a trade-off between efficiency and accuracy, necessitating a better approach for urban air pollution. Direct Emission Prediction (DEP), a GRU-based deep learning model, is introduced to predict $\text{CO}_2$ and $\text{NO}_x$ emissions from link-level inputs. This work demonstrates that deep learning can achieve microscopic accuracy at lower computational cost for scalable urban emission modeling.

Neighbor Crowding Predicts Feature Stability in Sparse Autoencoders

Sparse Autoencoders aim to identify stable language model representations by breaking down features. The study investigates feature stability across different training token levels using computationally cheap statistics instead of training multiple seeds. Neighbor crowding, a geometric property of the dictionary, is identified as the strongest predictor of feature stability. Features located in dense regions of the unit sphere are more likely to be stable than isolated ones. This work provides a method to predict feature stability without the expense of training multiple SAE seeds.

REI: Learning Ideation from Repository Evolution

Ideation in science and engineering is bottlenecked by the cost of exploration, which is addressed by learning from repository evolution. The proposed REI framework learns reusable ideation policies by analyzing code changes and subsequent reuse in repositories. A limitation identified is semantic diversity collapse, where generated ideas cluster in dominant method families, hindering generalization. Semantic Prior Optimization and Debiasing (SPOD) is introduced to mitigate this by making method identity explicit and correcting reward bias. Experiments show that REI with SPOD improves ideation quality, method diversity, and cross-task generalization.

Semantic Density Does Not Predict Agent-Memory Collapse

Persistent textual memory can help LLM agents, but repeated updates can degrade task performance. Research investigated whether memory statistics predict early declines in task accuracy. Various measures, including cosine similarity, geometry, and graph statistics, did not reliably predict task performance decline. Classifiers trained on these statistics failed to accurately flag memory collapse in real-world agent runs. The study concludes that global semantic density and local crowding did not serve as reliable warnings for agent-memory collapse.

KiRA: Kronecker Input-Gated Rank Adaptation for Parameter-Efficient Fine-Tuning of Pretrained Models

KiRA introduces Kronecker input-gated rank adaptation for parameter-efficient fine-tuning of pretrained models. It modifies low-rank updates by using the Kronecker product of a frozen matrix and a trainable input-dependent factor. An input gate $g(x)$ adjusts the rank of the update in discrete steps, allowing for input conditioning without increasing trainable parameters. This method demonstrated superior performance on six benchmarks compared to low-rank adaptation, requiring 8.7--9.7 times fewer trainable parameters. The approach successfully predicted the benefit of input conditioning based on labeled data.

The Symmetry Budget: How Much Group Structure Should a Network Architecture Assume?

Network architectures often rely on symmetry assumptions, such as convolution tying weights across translations. The paper investigates how much group structure a network should assume based on data symmetry. It analyzes a solvable model using linear maps over the cyclic group $\mathbb{Z}_d$ to study the trade-off between approximation and estimation error. The study shows that intermediate architectures are generally not optimal, pointing towards a phase boundary for optimality. Structured defects in symmetry can restore optimal performance, and the findings are validated by experimental measurements.

A Causal Energy Prior for Learning Directed Acyclic Graphs

Bayesian learning of Directed Acyclic Graphs (DAGs) often uses non-informative priors, which lack directional causal information. The proposed local-global energy prior (LGE) is a Gibbs distribution that combines local divergence, Structural Hamming Distance, and a causal Structural Intervention Distance. Rules are derived to calibrate the decay and weighting of these divergences based on the prior DAG. Simulations show that LGE improves the structural accuracy of maximum a posteriori DAGs and the fit of the resulting Bayesian networks. This method was demonstrated on a gene regulatory network learned from single-cell kidney data.

Evaluating Ensemble Methods for Algorithmic Stability Under Data Perturbations

Ensembling methods can destabilize classifiers that are already stable, although subbagging improves stability in certain settings. The effect of ensembling on stability depends on the perturbation level, introducing Monte Carlo noise that slowly decreases with more bags. The Rashomon set, representing models with near-optimal performance, can stabilize unstable classifiers by using predictive multiplicity. However, this stabilization is not guaranteed and is not a general replacement for subbagging. Results suggest ensemble methods stabilize unstable classifiers via influence equalization, but the mechanism differs for stable classifiers.

Gaussian priors from nonlinear PDEs with the semiclassical approximation

Probabilistic methods for solving partial differential equations treat the problem as a Bayesian inverse problem, often employing Gaussian priors for field reconstruction. This work utilizes the semiclassical approximation to construct Gaussian priors from variational energies or integrated square residuals for nonlinear PDEs. The prior is derived by expanding the PDE energy around a stable solution to uncover a Gaussian form. The covariance operator of the prior is determined by the inverse of the Hessian of the energy associated with the PDE solution space. The resulting prior's response to model-form error depends on the distance between the assumed model and the ground truth.

Centered Kernel Distance: Dimension-Free Error Bounds for Comparing Neural Representations

The Centered Kernel Distance (CKD) is introduced as a natural metric counterpart to representational similarity measures like CKA and RSA. The study demonstrates that CKD admits an unbiased estimator, unlike several popular similarity measures such as CKA. Estimation error for CKD decays proportionally to $1/M + 1/N$, independent of the dimensionality of experimental conditions. This finding shows that similarity estimation avoids the curse of dimensionality. Empirical verification was conducted across various neural network and biological data.

More data is not always beneficial for learning performance in sequential decision-making settings. The paper investigates whether extra reward samples in stochastic bandit setups guarantee a reduction in regret. Adversarial Bandit Convex Optimization with $d^{3/2}\sqrt{n}$ Regret

The paper studies adversarial bandit convex optimization where a learner selects points in a convex body and observes noisy convex loss values. The losses are manipulated by an adversary who adapts to the learner's past actions. The authors improve the regret bound for this problem to $\widetilde O(d^{3/2}\sqrt n)$, matching conjectured rates. This result, combined with a lower bound, determines the minimax regret up to a factor of $d^{1/6}$. The method employs an online Newton step with Gaussian exploration, using unbiased gradient and Hessian estimates.

Improved Sample Complexity of Robust Reinforcement Learning with KL Uncertainty Sets

The paper studies distributionally robust reinforcement learning using Kullback-Leibler (KL) divergence-defined uncertainty sets. The objective is to find a policy that maximizes the worst-case value over all possible transition kernels within the uncertainty set. The authors develop tighter and complete upper and lower bounds for the sample complexity of finding an $\epsilon$-optimal robust policy. The new upper bound improves upon existing results by an order of $\mathcal{O}(\min\{p_\wedge^{-1},(1-\gamma)^{-1}\})$. Furthermore, the lower bound holds across all uncertainty levels, showing better agreement between the bounds.

Understanding Double Descent through Universal Compression

Deep learning models often exhibit a double-descent phenomenon, where test loss peaks near the interpolation threshold before decreasing again, defying classical bias-variance predictions. This paper interprets this phenomenon using the concept of universal compression. The authors bound the maximum-likelihood excess test loss by summing four terms, including an approximation-and-shift term and a minimax batch regret. Experiments suggest that the gap between Maximum Likelihood Estimation and the Bayes predictor significantly contributes to the double-descent peak. Specifically, using a Gaussian-prior SGLD approximation shows no pronounced interpolation peak, but the gap is a major factor under uniform random labels.
