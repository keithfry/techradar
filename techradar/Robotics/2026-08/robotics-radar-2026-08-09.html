Cyborg roaches to the rescue?

Researchers from Nanyang Technological University (NTU) Singapore and Waseda University in Japan have developed a special diving suit for cyborg cockroaches to assist in search-and-rescue operations. The cyborg roaches are equipped with oxygen generation tanks and electronic controllers, allowing them to navigate underwater or on land for up to 3 hours. They can also withstand heavy rain, flooding, rubble, and narrow gaps.

ROS Discourse General: ROS2 Dev Container Feature + Workspace Update

A ROS2 Dev Container Feature was implemented, allowing users to select the ROS distro once in devcontainer.json and use the same configuration for local development and CI. The feature also updated VSCode ROS2 Workspace Template to use it instead of pre-built ROS Docker images. The main ROS distribution used is now "lyrical".

ROS Discourse General: Has a CPU shared-memory backend for rosidl::Buffer been explored?

A CPU shared-memory backend for rosidl::Buffer has not been extensively explored, but some middleware and RMW implementations already provide shared-memory transport optimizations. Conceptually, a Buffer backend could use shared memory to store large variable-length payloads while making the payload storage itself shared, complementing transport-level shared memory rather than replacing it. There is currently no related work or design discussion that has explicitly explored this specific direction for rosidl::Buffer.
