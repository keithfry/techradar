Robotic lab sets up and runs optics experiments on demand

MIT scientists developed a reconfigurable, robotic laser laboratory to automate the setup and running of complex optics experiments. The system uses a robotic arm to autonomously assemble optical components and fine-tune their alignment with micron-scale precision. This automation allows for the rapid building, running, and dismantling of experiments, enabling scientists to test materials for applications like solar cells. The system incorporates motorized tools and software to precisely manipulate components and autonomously correct for physical disturbances. This technology promises to significantly accelerate scientific research in fields dependent on precision optics.

Human-Centric Grasp State Assessment: Toward Transferring Subjective Evaluation to Robots

A framework is proposed to transfer tacit human subjective grasping criteria to robots for handling deformable objects. This addresses the semantic gap between qualitative human expectations and quantitative robotic measurements. The system integrates a Vision-Language Model for supervision with a lightweight predictor to adapt to unannotated grasping data. The prediction model allows for rapid online grasping state estimation from tactile and force measurements. Experiments confirm the framework's feasibility in adjusting grasping force based on human-perceived appropriateness.

Real-Time Service Robot Replanning via Simple Button Interaction for Improved Task Success and User Experience

Service robots can improve task success and user experience by incorporating real-time feedback mechanisms. Users can provide feedback to the robot by pressing a button when the robot performs incorrectly. Robots utilize this simple interaction to consider their failures and replan appropriate actions to complete the task. Experiments showed that this feedback function did not negatively impact the user experience. Specifically, the feedback improved user satisfaction regarding unexpected behavior and anxiety about the robot's actions.

Flexible-body Modeling, Kinematic Identification, and Assembly Accuracy of Overconstrained Spatial Linkages

Overconstrained spatial linkages, despite being compact, are difficult to model using rigid body formulations due to redundant constraints. A flexible multibody modeling framework based on the floating frame of reference is presented to address this issue. The study validates this framework experimentally with 3D-printed prototypes of mechanisms with intentional misalignment. Kinematic parameter identification methods are also provided for mechanisms with ill-conditioned Jacobians. Results show that these overconstrained mechanisms exhibit a self-assembling tendency driven by structural compliance.

LEAP: Learning Emergent Active Perception for Quadruped Navigation

The LEAP method learns emergent active perception for quadruped navigation without explicit task objective augmentation. It addresses goal-oriented navigation over hazardous terrains where goals must be discovered visually. The approach uses a gaze-invariant representation integrating depth images into egocentric belief maps to facilitate active perception. Training on a terrain curriculum allows task pressure alone to induce the emergence of gaze control. Validation showed LEAP achieves a 92.7% success rate in evaluation scenarios, outperforming scripted and passive perception methods.

Vision-Language Grounded Task-Context-Aware Imitation Learning for Robotic Disassembly

Real-world robotic disassembly demands long-horizon execution involving sequential manipulation tasks with diverse configurations. The proposed framework incorporates task context from language to guide skill selection and link instructions to visual targets in the scene. It combines hierarchical task selection with task-context-aware imitation learning to ground language in visual representations for disassembly. This method achieves generalization across various connector geometries and configurations without needing explicit object annotations. The approach results in significant improvements in end-to-end task success compared to existing baselines.

arXiv - cs.RO

RAF-VLA: Representation Alignment with the Future for End-to-End Autonomous Driving

Vision-Language-Action (VLA) models for autonomous driving use future scene generation for supervision, which incurs training burden and inference latency. RAF-VLA proposes aligning planning-relevant internal representations directly with future-frame representations to mitigate these issues. This is achieved through Future-Aligned Supervised Fine-Tuning, a simple regularization method. Experiments on the NAVSIM benchmark show RAF-VLA achieves competitive planning performance with fewer training samples. Furthermore, RAF-VLA introduces minimal overhead, with only 3.8% training and 1 ms inference overhead.

arXiv - cs.RO

CALOS: Control-Affine Lyapunov On-manifold Safety Layer for Safe Deep Reinforcement Learning for Quadrotors

CALOS is a runtime safety layer designed to enforce attitude constraints on quadrotors in Deep Reinforcement Learning without altering the core learning algorithm. It achieves this by formulating four tilt-angle inequalities and a Lyapunov descent condition into a single quadratic program. This program determines the minimum-norm correction to the policy's nominal torque output to satisfy the constraints. The solution is found efficiently using active-set enumeration over the three-dimensional torque space, allowing for real-time constraint enforcement in parallel environments. Evaluation showed CALOS reduced lateral tracking error by 55-60% compared to unconstrained policies while ensuring zero attitude-constraint violations during training.

arXiv - cs.RO

HINT-Plan: Human Intention-Aware Robot Task Planning in Context-Rich Environments using Vision Language Models

HINT-Plan is a novel approach to human intention-aware robot task planning by integrating human intention prediction into robot decision-making. It utilizes Vision Language Models (VLMs) to anticipate human intentions from images and convert them into goal states for task planning. The method uses hierarchical Scene Graphs to represent the environment and translates knowledge into formal planning language for executable plans. Evaluation in simulation showed HINT-Plan achieved a 69.71% success rate, significantly outperforming baselines by up to 35.29%. This demonstrates the effectiveness of incorporating inferred human intentions into multi-agent task planning.
