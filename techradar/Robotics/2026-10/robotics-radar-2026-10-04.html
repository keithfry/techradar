RoboParty Unveils RP1 Humanoid at IROS, Plans Broader Open-Source Release in Q4

RoboParty unveiled the RP1 humanoid robot at IROS on September 28th. This robot demonstrates balance recovery capabilities and peak joint torques up to 160 N·m. Broader releases of the RP1, including the full stack, are planned for the fourth quarter. The company intends to progressively release motion control, simulation environments, SDKs, and PartyOS to the community. Developers can access resources from the earlier ROBOTO ORIGIN repository as a starting point.

ROS Discourse General: Tuning StereoSGBM on PS5 Camera (ROS 2 Galactic) for Dense Depth Maps

A user is attempting to tune StereoSGBM parameters in ROS 2 Galactic for dense depth map estimation from a PS5 stereo camera. The goal is to produce a dense point cloud suitable for 3D reconstruction using RTAB-Map. The user is struggling to achieve smooth depth maps, as adjustments lead to outputs that are either extremely sparse or overly noisy. Attempts to tune parameters like correlation window size, uniqueness ratio, and speckle settings have yielded inconsistent results. The user is seeking advice on missing pre-filtering steps or calibration issues specific to their camera setup.

ROS Discourse General: RobotCAD v12.10.0 is released!

RobotCAD v12.10.0 has been released, introducing several new features and fixes. New additions include a RobotCAD MCP server for agentic robot assembling and an updated Models Library with faster import capabilities for xacro and mjcf models. The release also added a sensors field of view feature and improved compatibility for external document links and coordinate systems. Furthermore, it includes support for Sverk, an aerial robot framework, and a vacuum gripper tool for Gazebo.

ROS Discourse General: Has anyone found a reliable way to validate a hand eye calibration result?

Finding a reliable method to validate hand-eye calibration results remains an unresolved issue. Existing tools provide reprojection error or transform data, but there is no clear consensus on how to trust these results. Visual inspection in RViz is insufficient for proper validation, especially concerning scale. The author seeks practical methods, such as validation motions or comparing against measured poses, that do not require expert judgment. Ultimately, the community needs to establish a standard procedure for confirming the accuracy of these calibration results.
