Tencent Open-Sources DFly2: Speculative Decoding That Reuses the Target’s Sparse KV Cache

Tencent open-sourced DFly2, a speculative decoding drafter designed for natively sparse Large Language Models. DFly2 achieves this by reusing the target model's sparse Key-Value (KV) cache and indexer selections, eliminating the need for a separate draft KV cache. Benchmarks show DFly2 achieves up to 81% more throughput on DeepSeek-V4.1-Flash at 64K context, while also outperforming DSpark on long-context and agentic workloads. The method reduces memory overhead for draft caches, allowing more requests to be served within the same memory pool. DFly2 is integrated into Tencent's Hy4 flash and can be trained on other sparse models using AngelSpec.

Code Mode vs. Tool Calling Benchmarks Find a 16-Tool Crossover

Code Mode moves execution outside the context window by having the model write and execute code, which reduces context load for intermediate results. It demonstrates significant cost and time savings, especially for repetitive or fan-out tasks, with a crossover point around 16 tools for single-step tasks. For fan-out tasks, Code Mode is consistently cheaper and faster, reducing costs by up to 120 times compared to plain tool calling. However, Code Mode is not a universal solution, as it can fail on complex multi-step tasks or with less capable models. Therefore, Code Mode is most beneficial when handling many tools and item-heavy workloads, not as a default for all agent tasks.

How to Calculate Customer Lifetime Value (CLV) in E-Commerce

Customer Lifetime Value (CLV) is a unit-economics metric estimating the total profit a business can expect from a single customer relationship over its lifespan. It shifts focus from individual transactions to the cumulative value incorporating sales, margins, frequency, retention, and acquisition costs. Calculating CLV involves summing discounted future revenue minus costs, utilizing models like Buy 'Til You Die (BTYD) to estimate customer lifespan in non-contractual settings. Operationalizing CLV requires mapping revenue and costs to lifecycle events, identifying High-Value Actions (HVAs), and using behavioral segmentation like RFM. Ultimately, effective CLV management involves strategically investing in interventions where the marginal CLV uplift exceeds the cost of the action.
