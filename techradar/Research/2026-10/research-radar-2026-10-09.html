An Explainable Header-Centric Framework for Large-Scale Semantic Table Interpretation and Data Quality Assessment

An explainable, header-centric framework is presented for metadata-only Semantic Table Interpretation and Data Quality Assessment. This framework maps column headers to 39 interpretable FinalFormat types using lexical resources and token-level traceability. It activates validation rules based on a Data Quality Issues taxonomy to detect problems like missing data or wrong data types. These detections are aggregated into HeadersIQ, a lightweight quality metric. The method was evaluated on heterogeneous benchmarks, showing broad practical coverage across real-world metadata.

Synthesis Through Simulation: Generating Coherent Enterprise Data via Scalable Agent-System Interaction

Synthesis Through Simulation (STS) is a schema-free data synthesis paradigm where an LLM agent generates data by interacting with policy-enforcing APIs in simulated enterprise environments. STS guarantees structural validity by construction because data generation occurs within the validating environment, decoupling validity from distribution modeling. The Generalist Populator (GP) agent addresses distributional fidelity and scalability, achieving 0.88 average marginal fidelity across ten environments without needing database schemas. The GP agent successfully satisfies constraints in all ten environments, unlike schema-privileged agents which fail on complex workflows. The full framework, environments, and generated datasets are open-sourced.

Agent-Controlled Forgetting for Tool-Using Agents: Reversible Context Curation in Practice

Agent-controlled forgetting involves having the acting model select previously observed tool results and replace them with short notes while retaining the original results in a recoverable archive. A Python harness allows for batch archival and explicit recovery without task-specific model training, protecting user instructions. Experimental results showed significant resource savings in noisy tool-use trajectories, with reduced input tokens and lower estimated API costs. However, some specific evaluations did not fully satisfy the follow-up assessments. The findings indicate that workload dependence is a central factor when managing reversible context for these agents.

Verification and Self-Improvement in Agentic AI: Foundations and Limits

Agentic AI can improve through methods like longer searches or modifications to output verification. The work compares these mechanisms using bounded verification with hidden terminal randomness to define mathematical languages. The study shows that independent majority amplification preserves certain languages, while existential acceptance over random tapes can allow incorrect outputs. Exact verification is achieved in the zero-randomness case, and the framework links self-improvement claims to requirements on correctness and evidence. Ultimately, the work establishes a framework for auditing self-improvement in agentic systems.

The Harness as the Only Mutable Surface: Compliance-Bounded Self-Evolution of LLM Agents in Credit Pipelines, with a Measured Admission Gate

Self-improving LLM agents in credit pipelines must confine their evolution to the runtime harness, such as instruction text and tool-call logic, while keeping model weights fixed. A dual-loop engine with a measured admission gate was developed to ensure self-evolution remains reviewable with attached change logs and tests. Simulation showed the gated loop successfully admitted changes that did not worsen errors or raised missed flags in supervisory evaluations. Replacing the gate with an unbounded system allowed for more harmful changes, demonstrating the gate's role in error control. The findings relate mechanisms to the EU AI Act's provisions for high-risk credit scoring.

Plan-and-Patch: Diffusion Language Models for Agentic Planning

Planning for long-horizon agent tasks requires the ability to revise plans effectively when outcomes are unexpected. Plan-and-Patch introduces a framework using diffusion language models (dLLMs) to generate structured plans and repair them by filling in modified regions while preserving the surrounding structure. The method compares diffusion models against autoregressive planners in plan generation and repair tasks. Diffusion models show superior plan repair success rates over autoregressive models without task-specific training. Overall, Plan-and-Patch offers a framework for faster plan generation and more effective plan repair for agents.

On the Clock: Towards Punctual and Productive Time-Budgeted AI Agents

The study investigates whether small LLM agents can operate effectively while adhering to explicit time budgets and using the allocated time productively. Agents often fail to control time use due to a lack of time awareness and inability to anticipate action durations. Interventions involving timing information and reinforcement learning with budget-aware rewards improve budget adherence but do not necessarily increase task performance. A central challenge identified is the gap between respecting time limits and actually utilizing the time to improve task performance. Results indicate that even when adhering to budgets, agents still struggle to allocate extra time productively.

Freeze the Decoder, Heal the Encoder: Parameter-Efficient Adaptation for SVD-Based KV-Cache Compression

SVD-based KV-cache compression involves using an encoder and decoder to factorize key/value weights, followed by a fine-tuning step to recover accuracy. A shared learning rate often creates misleading advantages when comparing fine-tuning recipes with different parameter counts. Freezing the decoder and only healing the encoder demonstrated a superior result compared to other methods under a shared learning rate. Tuning learning rates per arm eliminates this apparent advantage, showing that encoder-only healing achieves parity with other approaches. This method offers a memory-efficient way to retrofit low-rank KV-cache compression.

Coverage, Not Difficulty, Sets How Much Synthetic Data an Activation Probe Needs

Activation probes monitoring language models require synthetic data whose amount is determined by coverage rather than difficulty. The required sample size is set by the need to saturate the distribution for each type of monitored concept. Median "half-gain" size for each concept is found to be between 7 and 11 own-kind synthetic samples. The required breadth of data differs by concept, with instruction probes needing more kinds of data, while high-stakes probes show redundancy. Coverage, not difficulty, dictates the necessary quantity of synthetic data for effective monitoring.

When Routing Reveals Membership: Privacy Leakage from MoE Router Telemetry

Mixture-of-Experts (MoE) models generate routing telemetry during inference, which can reveal information about the model's internal computation. This telemetry introduces a privacy concern regarding membership inference, specifically whether an example was used for fine-tuning. A router-augmented membership inference attack, combining output signals with routing features, consistently improves membership inference across various MoE architectures and data domains. Leakage persists even when fine-tuning is frozen, suggesting the router exposes a projection of fine-tuning signals. Consequently, router telemetry acts as an additional privacy surface for fine-tuned MoE models.

Self-Organization from Constrained Geometric Radiation

Spontaneous self-organization in closed systems is investigated through constraint-induced self-organization via geometric radiation in coupled metric evolution systems. Simulations reveal a four-stage cycle: stress accumulation, super-exponential radiation, chaotic collapse, and convergence to a fractal limit cycle, termed the wedge-shaped attractor. Four jointly sufficient conditions, including an irreversible geometric horizon and persistent stress injection, are identified as triggers for this process. The research proves theorems related to geometric horizons, energy dissipation, and radiation as a phase transition channel. This work establishes a new paradigm for closed-system self-organization by linking nonlinear constraints and gravitational horizons.

Recurrent Self-Improvement: Dynamic Cross-Loop On-Policy Distillation for Looped Language Models

Looped Language Models (LoopLMs) present a parameter-efficient method for scaling reasoning by reusing parameters across recurrent steps, but post-training is difficult. LoopOPD introduces a cross-loop on-policy distillation framework using recurrent computation within the LoopLM as its own supervision source. Dynamic LoopOPD further refines this by continually updating the terminal loop teacher during parameter updates for recurrent self-improvement. Experiments show that this method improves mathematical reasoning and extends to general reasoning and code generation benchmarks. Recurrent computation proves to be an effective source of supervision for LoopLMs.

Exact SO(3)-Equivariant Isotropic Kernels for Rotation-Robust Neural Dynamics

Neural surrogates for vector-valued PDEs fail when physical states are rotated in a coordinate frame. The Invariant-Conditioned Isotropic Kernel Neural Operator (IKNO) is introduced to address this by building interactions from rotation-invariant scalar quantities. This method ensures that rotating inputs result in the same rotation of the predicted velocity change. IKNO achieves this rotation-robustness while matching forecasting accuracy with significantly fewer parameters than other rotation-aware models. Consequently, a compact, PDE-specialized model can eliminate coordinate dependence without sacrificing predictive quality.

Phase-HDC: Replacing Optimizer History with Gradient Thresholds in Discrete Phase Learning

Phase-HDC proposes replacing optimizer history storage with gradient thresholds in discrete phase learning. It achieves this by updating each angle by at most one step based on the sign of the current gradient when the gradient is sufficiently large. This method is shown to be the exact solution for a first-order loss model where parameter changes have a fixed cost. Phase-HDC achieves accuracy comparable to Adam with 6-bit moments while storing significantly less memory across various datasets. The method demonstrates substantial storage savings compared to standard float32 and 8-bit Adam implementations.

The optimal information complexity of VC learning

The research investigates the optimal information complexity for VC learning using the Conditional Mutual Information (CMI) framework. The authors explore whether the optimal PAC guarantee for VC classes can be recovered from algorithm-dependent information-theoretic quantities. They demonstrate that this guarantee can be recovered by constructing a learning algorithm whose eCMI is of order $O(d)$, where $d$ is the VC-dimension. Specifically, this is achieved with a randomized Majority-of-5 base learner that provides optimal in-expectation generalization. This work connects information theory to the generalization guarantees of machine learning algorithms.

From Log-Odds to Shapley Values: An Explanatory Geometry for the Weighted Naive Bayes Classifier

The paper explores constructing an explanatory space for a weighted Naive Bayes classifier using a supervised representation. It reformulates the classical supervised distance based on conditional log-likelihoods into a discriminative representation using log-odds. This representation induces a distance that exactly matches the $\ell_1$ distance between vectors of analytical Shapley values. The work formally interprets the geometry induced by the model through this link to supervised distance and local explanation. Finally, empirical comparisons are made across several supervised distances using a $k$-nearest neighbors classifier.

Calibrating Ambiguity Set via Diagnostic Transport for Distributionally Robust Optimization

Distributionally robust optimization (DRO) optimizes decisions over an ambiguity set, but poorly aligned sets can lead to overly conservative results. Diagnostic-transport DRO (DT-DRO) addresses this by using calibration data to adapt the ambiguity set geometry based on observed predictive errors. DT-DRO employs the conditional probability integral transform cumulative distribution function to diagnose misallocation and translate this into an outcome-level transport. This method results in a computationally tractable dual reformulation and provides tighter robustness guarantees. Experiments show DT-DRO improves decision quality, especially under structural and tail misspecification.

Transformed Samplers with Variance Reduction

MCMC methods often use control variates to reduce estimation variance, but finding these requires solving a complex Poisson equation. The work extends solutions for samplers with a known spectral decomposition to general targets using a learned change of variables, like a normalizing flow. This transformation allows Markov kernels and their Poisson solutions to be mapped, yielding explicit control variates in the latent space. Experiments confirm that this method performs well compared to existing state-of-the-art techniques.

A General $\widetilde{\Omega}(\sqrt{T \gamma_T})$ Lower Bound for Kernel Bandits

The paper establishes a general $\Omega(\sqrt{T\gamma_T/\log T})$ minimax regret lower bound for kernel bandits with non-constant continuous kernels. This result addresses the lack of lower bounds for general kernels, contrasting with existing upper bounds that scale as $\sqrt{T\gamma_T}$ up to log factors. The authors show that the log factor is generally unavoidable but can be removed under specific conditions. The findings imply that the minimax-optimal scaling is exactly $\Theta(\sqrt{T\gamma_T})$ for certain specific kernels like Matérn and $\gamma$-exponential.

Accelerating Non-Smooth and Heavy-Tailed Sampling

Anchored Langevin dynamics (ALD) and reflected anchored Langevin dynamics (RALD) are useful for sampling non-smooth, heavy-tailed distributions. The paper proposes non-reversible anchored Langevin dynamics (NALD) and non-reversible reflected anchored Langevin dynamics (NRALD) to handle non-differentiable densities. These methods introduce a circulation drift to accelerate sampling by breaking reversibility. Finite-time non-asymptotic analysis demonstrates that NALD and NRALD can converge faster than reversible methods. Numerical experiments confirm the efficiency of these proposed algorithms for sampling.

Synthetic tabular data generators often focus on distributional fidelity, which does not guarantee the preservation of causal effects. The authors address this by proposing a framework to improve causal fidelity directly within a generative model.
