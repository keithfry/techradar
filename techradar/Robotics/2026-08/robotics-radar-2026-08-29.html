The Sequence Robotics - Issue #922: Learning About LeRobot: The Transformers Moment for Robots

Robotics is experiencing a "Transformers moment" with a coordinated effort called LeRobot. Previously, robot learning suffered from fragmented setups, with each lab using incompatible datasets, rigs, and training loops. LeRobot's approach shifts the focus from model-centric learning to coordination-limited learning, similar to how Hugging Face shipped a protocol instead of just a model. This library has become the default substrate for open robot learning, drawing support from organizations like NVIDIA. Essentially, LeRobot aims to provide a unified framework for robot learning by shipping a protocol rather than just a model.
