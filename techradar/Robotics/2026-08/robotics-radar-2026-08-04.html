Track-Guided Hierarchical Reinforcement Learning for Autonomous Vehicle Drifting with Minimum-Lap-Time Planning

A planning-control framework is proposed for Minimum-Lap-Time (MLT) drifting in autonomous vehicles. The framework uses a Track-Guided Reinforcement Learning (TgRL) drift control method to learn a drift racing policy that optimizes both vehicle motion control and lap time reduction. The reward function incorporates an instant reward term and an end reward term derived from the MLT objective, allowing the agent to learn progressively from drift control policies to comprehensive drift race policies. Simulation results demonstrate effective learning of a drift racing policy that reduces lap times while maintaining vehicle motion control performance.

Motion Planning for Mobile Manipulators Navigating Doorways via Model Predictive Control

A motion planning framework generates dynamically feasible and collision-free trajectories for autonomously opening and traversing both push and pull doors using a nonlinear Model Predictive Control (MPC) optimization framework. The robot and door are formulated as a coupled dynamical system, with manipulation feasibility enforced through a penalty-based constraint. Simulations and a hardware experiment demonstrate the approach's success in planning feasible trajectories for door traversal.

Developing Combined Manipulation and Locomotion Skills with Interaction Representation and Skill Composition

Researchers Fanxing Meng and Jing Xiao developed a method to enable humanoid robots to learn combined manipulation and locomotion skills using interaction representation and skill composition. The approach learns a whole-body reaching and grasping policy via spatial convolution, followed by combining it with a separately learned getting-up policy to create a more complex policy. This results in a 93% zero-shot success rate for grasping unseen objects and a 96-100% success rate for standing up while holding the object.

arXiv - cs.RO

Localization in Spatiotemporal Fields via Environmental PDEs

A localization framework uses spatiotemporal fields governed by partial differential equations (PDEs) as signatures for vehicle localization. The PDE classes considered include the shallow water equations and the advection-diffusion equation, which model free-surface flows in coastal and riverine environments and transport and mixing of scalar quantities. A Rao-Blackwellized particle filter improves localization accuracy by fusing multiple field channels. Simulation studies demonstrate that this framework outperforms a standard particle filter in terms of final position error and Root Mean Square Error (RMSE).

Hybrid Attention Estimation Pipeline for Adaptive HRI Using an Expressive Robotic Head

A hybrid attention estimation pipeline was developed for adaptive human-robot interaction (HRI) using an expressive robotic head based on the InMoov ecosystem.
