Opinion: How robots are learning to navigate the building site

Autonomous robots are being developed to navigate construction sites without relying on GPS, using Simultaneous Localisation and Mapping (SLAM) technology. SLAM builds a map of the environment using cameras or Light Detection and Ranging (LiDAR) sensors, combining localization and mapping to create a living map that adapts to the changing site. While SLAM has the potential to improve safety, productivity, and error reduction on construction sites, it is not a drop-in replacement for current methods and is subject to challenges such as airborne dust, physical debris, and integration with existing site management software.

FetchMan: Learning Visual Humanoid Loco-Manipulation Policies from Simulated Experiences

Researchers developed FetchMan, a policy learning approach that enables visual humanoid loco-manipulation policies to generalize to novel scenes and objects. By learning from simulated data and refining the cloned policy with Flow-GRPO, FetchMan achieves performance that synthetic behavior cloning cannot match. On a real Unitree G1, FetchMan's single-object reach-and-pick policy achieves 73.3% success. The researchers extend this approach to multi-object training, a step toward creating generalist policies.

Lambda-Hold Control: Human-Like Movement Emerges from a Minimal Task Reward in Predictive Musculoskeletal Simulation

A minimal task reward enables a muscle-actuated skeletal model to learn human-like sprinting, emerging from a predictive musculoskeletal simulation with the proposed $\lambda$-hold controller. The controller, grounded in physiology, enables efficient exploration through an equilibrium-point threshold length $\lambda$, reducing the frequency of querying. Terrain-Aware Local Path Planning with Global DEM Data Integration for Autonomous UGV Navigation

Researchers have proposed a hybrid framework that integrates low-resolution Digital Elevation Model (DEM) data with real-time LiDAR-based obstacle detection and terrain analysis for efficient path planning in autonomous unmanned ground vehicles (UGVs). A global path is initially computed using a preprocessed DEM-based A* algorithm, and subsequently, local sensor data drives adaptive path correction to enable the UGV to navigate sudden environmental changes while maintaining safety and efficiency. Simulation results demonstrate significant improvements over a baseline approach, achieving a 95% obstacle avoidance rate and reducing the average encountered slope from $8^\circ$ to $2.7^\circ$ in custom terrain.

In its general form, a multimodal agent turns a few successful demonstrations into reusable Skill Blocks, which are then composed to achieve meaningful subgoals. ORPA: Online Residual Policy Adaptation for Robot Manipulation Control with Human Feedback

ORPA, a framework for immediate, feedback-driven correction of robot actions, augments a pretrained control policy with a lightweight, feedback-conditioned module that predicts residual adjustments in joint space. This allows the system to adapt its behavior at runtime. ORPA is evaluated on precision-sensitive manipulation tasks using the ALOHA platform, demonstrating improvements in success rate and recovery from small perturbations. ORPA outperforms baseline control policies and rule-based inverse kinematics corrections.

Reconfiguration-Complete Motion Primitives with Constructive Planning for Deformable Planar Modular Robots

Researchers Jie Gu and six others introduced a square-cell abstraction to map deformable rhombus modules to fixed-size grid cells, enabling the definition of reconfiguration planning and analysis for modular robots. The abstraction introduces two primitives, pivoting and shearing, which allow for the transformation of any non-straight edge-connected configuration with 7 or more modules to a fixed canonical staircase. The staircase-canonicalization planner is constructive and preserves connectivity, and a boundary-to-delivery lookahead selector reduces planning time. Experiments demonstrate the effectiveness of the new framework, which outperforms prior frameworks.

MANIGUARD: A Benchmark and Data Suite for Specification-Grounded Safety Evaluation and Improvement of Robotic Manipulation

ManiGuard is a specification-grounded framework for evaluating and improving the safety of foundation-model manipulation in robotics. It includes a benchmark suite, ManiGuard-Bench, which organizes tasks into 200 locked base tasks and provides 1,000 scenarios with safety specifications fixed. Evaluating safety independently of task success is crucial, as 6-21% of successful rollouts violate the specification.
