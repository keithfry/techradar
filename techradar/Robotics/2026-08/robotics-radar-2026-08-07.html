AI agents create virtual playgrounds to help robots get crucial training data

A new system called SceneSmith, developed at MIT CSAIL and Toyota Research Institute, uses three agents to create realistic 3D scenes that can be used to train robots. The system's virtual environments are generated using a multi-modal vision-language model (VLM) called GPT-5.2, which is trained on internet text and images. These virtual playgrounds allow robots to practice skills and try out different ways of doing tasks before they're powered on, reducing the need for real-world testing. The scenes created by SceneSmith are more realistic and detailed than prior systems, with a high success rate in evaluating robot actions and improving roboticists' approaches.

ROS Discourse General: [GSoC 2026] ROS 2 Client Library Performance Monitoring: Midterm Progress Update

The ROS 2 Client Library Performance Monitoring project aims to connect benchmark execution, result processing, and visualization. The CLI workflow runs a reduced rclcpp benchmark matrix, converts raw outputs into JSONL format, and supports multiple communication modes and layouts. A public dashboard provides interactive analysis with features such as latency, throughput, CPU usage, memory usage, and message reliability comparison views. The project is still in progress, focusing on improving repeated run summaries and handling incomplete upstream benchmark data.

VLAff: Vision-Language-Affordance Model for Unified Actionable Affordances

VLAff, a vision-language model-based unified foundation model, learns cross-modal correlations across actionable affordances, including visual affordance heatmaps, grasp poses, and trajectories. This allows VLAff to generate directly executable actions from visual observations and instructions. VLAff achieves state-of-the-art performance on visual affordance prediction and demonstrates effective application in real robot applications, such as zero-shot manipulation and affordance-guided robot learning. The model utilizes 3D scene information for conversion into executable actions.

Failing Gracefully: Mitigating Impact of Inevitable Robot Failures

Researchers Duc M. Nguyen and colleagues introduce a novel safety formulation to evaluate the probability and severity of impactful interactions between robots and surrounding entities during failures, enabling informed planning decisions that balance safety with task efficiency. They also present FailBench, a MuJoCo-based simulation framework for studying robot-environment interactions under diverse failure modes. The approach provides a foundation for developing safer and more robust motion plans and learned policies in real-world household environments.

World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation

World-to-Wrist: Task-Conditioned Future Wrist Modeling for Fine-Grained Robot Manipulation presents a VLA model that contextualizes wrist local interactions under global task context. The model forecasts future wrist latents, transforming them into future-aware context for action prediction. Experiments demonstrate improved fine-grained and contact-sensitive manipulation across single-arm and bimanual settings, with action-generation rates above 80 Hz.

Sliding Sensors: Configurable Confidence in State Estimation for Continuum Robots

A concept hardware design has been presented to enable mechanically reconfigurable sensing in continuum robots, allowing uncertainty-shaping in state estimation. A sensor can be longitudinally translated within the robot, demonstrating a reduction of full-body shape estimation errors when sliding the sensor back and forth over time. This approach enables achieving sufficient confidence at task-relevant locations along the robot, prioritizing accuracy where it is most needed.

ARGUS: Aligning Robot Scene Geometry Under Shifting Views with Large 3D Vision Models

ARGUS, an observation pre-processing pipeline, uses large-scale 3D vision models to align image observations from arbitrary camera viewpoints into a canonical viewpoint before passing it to downstream visuomotor policies. This approach outperforms prior methods in efficiency comparisons and consistently improves success rates when learning from view-diverse data, converging up to 4-6x faster than previous methods by leveraging a simplified observation space.

PathCover: A Fast Convex Decomposition along a Path via Randomized Iterative Space Partitioning (RISP) on Point Clouds

PathCover, a framework driven by Randomized Iterative Space Partitioning (RISP), generates obstacle-free regions for autonomous robot navigation. It constructs convex polytopes directly from raw point cloud data in expected linear time and achieves an order-of-magnitude speedup over state-of-the-art methods while maintaining comparable corridor volumes.

KILVO: Kinematic-Inertial-LiDAR-Visual Odometry with Robust Multimodal Adaptation for Humanoid Robots

KILVO (Kinematic-Inertial-LiDAR-Visual Odometry with Robust Multimodal Adaptation for Humanoid Robots) is a odometry system tailored to humanoid robots, utilizing joint encoders, IMU, LiDAR, and camera sensors within an asynchronous-sequential hybrid error-state iterated Kalman filter (ESIKF). The framework achieves highly competitive accuracy, efficiency, and output rates with strong robustness against sensor degradation and failures.
