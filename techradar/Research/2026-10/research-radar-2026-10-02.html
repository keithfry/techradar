Heavy-Tailed Memory Traces in Long-Horizon Language Agents

Long-horizon language agents use external memory where memory use exhibits heavy-tailed traces, concentrating on a core while rare states accumulate prediction errors. This effect is reproducible and depends on the agent's policy, with semantic LLM policies yielding the strongest truncated-power-law-compatible traces. The authors propose the Core--Tail World Model (CTWM), a rank-based memory controller to manage prompt budget effectively. Applying CTWM reduces prompt tokens and lowers prediction errors relative to baseline memory methods on synthetic graph worlds. These findings suggest heavy-tailed memory traces serve as a practical control signal for token-efficient agent world models.

When Do Causal World Models Help Modular LLM Agents

Causal world models are studied for modular LLM agents where actions in one module affect others. The research introduces FedCausalCompose, a framework using causal world-models to provide intervention-response evidence for cross-module interfaces. Causal interfaces prove most beneficial in structured tool environments where API signatures reveal preconditions and effects. However, this benefit is less pronounced in dialogue and narrative settings unless causal information is explicitly made relevant at action time. Therefore, causal world models are most helpful when cross-module interfaces are statistically identifiable and presented in an actionable format.

From Proposal to Verified Effect: Praxa, an Evidence-Bound Harness for Governed AI Agent Execution

Praxa is an agent harness designed to explicitly represent the states of proposal, authority, dispatch, and verified external effect in AI agent execution. It introduces mechanisms for deterministic admission, brokered execution, external read-back, reconciliation, and reviewed promotion. The research presents four evidence lanes, including repository audits, pilot testing, and comparative development analyses. While demonstrating an evidence-bound architecture for making authority-to-effect transitions testable, the current evidence does not establish superiority in security, safety, or performance metrics. Ultimately, Praxa's contribution is an explicit and testable framework rather than a proven lift in autonomous capability.

What Do Rationales Communicate? A Message-Intervention Study in Role-Specialized QA

Role-specialized QA pipelines pass rationales between reasoners and verifiers, but the effect is unclear regarding answer accuracy or support assessment. A message-intervention diagnostic showed that adding faithful rationales adds little to answer accuracy, but corrupted rationales significantly alter support judgments. Corrupted rationales strongly shift support judgments, and human audits reveal that models often accept corrupted rationales. The study concludes that rationale sharing should be evaluated as a verification-message mechanism rather than solely as a route to better answers.

Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness?

Agent harnesses often require small language models (SLMs) for microtasks like command approval and tool selection. A benchmark was created to measure if off-the-shelf SLMs meet practitioner-defined thresholds, which are anchored to a non-LLM baseline. The study found an "eligibility gap" where most configurations failed to meet these thresholds across various models. Quantization to 4-bit did not substantially change this gap, suggesting the issue tracks model size rather than mere precision. The practical implication is to use SLMs only when a performance deficit compared to a baseline is observed.

Characterizing a Configuration Where Inference-Time PRM-Pruned Fragment Grafting Is Inert: Evidence from Three Reasoning LMs

The study investigates the effectiveness of inference-time PRM-Pruned Fragment Grafting (PPFG) for transferring knowledge in reasoning Language Models. The research tests PPFG on Qwen2.5-7B-Instruct with Math-Shepherd across multiple benchmarks and models. Results indicate that PPFG is statistically indistinguishable from an independent parallel Chain-of-Thought baseline in stagnation and random-targeting scenarios. The analysis reveals that injected grafts often target chains that were already successful or near completion, suggesting the mechanism is not heuristic-specific. The work contributes an equivalence-testing template to establish nulls for inference-time mechanism effects.

Scientific Agents: Evaluating Profession-Specific System Prompts on Scientific Tasks

Profession-specific system prompts increase token usage and cost without providing a consistent accuracy improvement for scientific tasks. Evaluation of Scientific Agents showed no statistically clear accuracy gain from using these detailed profiles over baseline settings. Matched profiles resulted in significantly higher token usage and cost per successful call to the model. While longer prompts offered a minor advantage in specific error scenarios, this was attributed more to prompt length than domain expertise. Loading full profession profiles by default did not improve accuracy or cost considerably.

Comedic Fool's Gold: Reward Exploits and Countermeasures in Conversational Humor

The research investigates reward exploits and countermeasures in training language models for conversational humor. Two methods are explored to capture understandable surprise and predicted audience amusement, testing how models react to word-shuffled replies. A fluency filter attempts to detect these shuffles, but the combined reward system still allows some exploits. Normalizing laughter cues across speakers blocks some attacks, though unmatched expressions remain exploitable. The study concludes that countermeasures must block exploitable shortcuts while maintaining the intended behavior of the reward.

Conformal Adversarial Generative Ensemble

The Conformal Adversarial Generative Ensemble (CAGE) is a novel framework designed to improve time series forecasting by mitigating the influence of extreme forecasts. It integrates generative modeling, adversarial discrimination, and conformal prediction to enhance forecast reliability. CAGE uses multiple generative models to create initial forecasts, which are then assessed by a discriminative component employing conformal prediction. P-values from nonconformity scores dynamically adjust model weights, ensuring only credible predictions influence the final ensemble output. Empirical results on milk collection and public health data show CAGE outperforms traditional ensembles in handling noise and outliers.

DualCast: A Dual-Path Language Model for Bimodal Financial Time-Series Forecasting

DualCast is a dual-path language model framework designed for bimodal financial time-series forecasting. It utilizes a frozen language model augmented with a discrete financial vocabulary, representing log-return patches with summary tokens. A fast path trains embeddings on a frozen backbone, while a slow path uses a toggleable LoRA adapter to condition on external news for revised predictions. The slow path, optimized with a return-space group policy, achieved the lowest mean absolute percentage error in several evaluations. This approach effectively combines a fast numerical forecaster with an optional text-conditioned revision mechanism.

FlashDiffusion: Fused Tiled Kernel Spectral Decomposition

Diffusion maps and kernel methods offer an interpretable spectral representation for geometric learning. Dense Gaussian kernel methods require $O(N^2)$ memory, which is prohibitive for high-rank matrices. FlashDiffusion is a matrix-free method that evaluates dense Gaussian kernel blocks using fused GPU tiles. It couples the eigensolver with an empirical $\beta$-flow to select the finite-sample resolution scale. This approach warm-starts expensive spectral solves by continuing over coarser resolutions.

Kinematic signatures of impairment: Detecting alcohol intoxication in e-scooter riders using sensor data and machine learning

Alcohol intoxication is a risk factor for e-scooter crashes, necessitating real-time impairment detection. Researchers used sensor data from an instrumented e-scooter and a six-axis IMU to study kinematic signatures of impairment. Analysis of normalized permutation entropy and standard deviation revealed that intoxicated riders exhibit reduced temporal complexity and increased signal amplitude compared to sober riders. A machine learning classifier achieved 85% accuracy in distinguishing between sober and intoxicated states based on these kinematic features. This work establishes a method using onboard sensing and entropy analysis for automatic intoxication detection in e-scooter riders.

Activation-Conditioned Self-Distillation

Activation-Conditioned Self-Distillation (ACSD) extracts a steering vector by contrasting activations of self-generated trajectories leading to correct answers against other trajectories. A frozen base model applies this vector to predict the next token based on student-generated prefixes. The student learns from the next-token distributions of these prefixes, utilizing outcome verification for direction construction and calibration. Distillation is performed without needing problem-specific reference text or teacher parameter updates. ACSD achieves the highest mean accuracy across four mathematical benchmarks among evaluated methods.

Weighted Data Selection: Sharp Upper-Half and Five-Dimensional Laws

The paper investigates the risk retained by a small reweighted training set in finite weighted least squares with a minimum-norm learner. It proves the exact law $\Gamma_d(n)=3-n/d$ for the specific range $\lceil3d/2\rceil\leq n\leq2d-1$. The guarantee is achieved by using selections that preserve the full feature span, employing balanced simplex anchors, and methods like positive-weight lifting. For a specific small budget $(d,n)=(5,6)$, the bound $\Gamma_5(6)=11/5$ is matched, with a sharpness of $6/5$ verified using circuit-based and geometric methods.

Target-Dependent Limits of Causal Repair: A Leading-Log Frontier in a Gaussian Model

The research quantifies the gap between how much a causal predictor can improve and the gain actually learned during a causal repair in a Gaussian model. It uses auxiliary data to estimate effect magnitudes up to bounded contamination and diagnostics to identify direction in a causal experiment. Joint optimization of the learner and assessor under a uniform learning MSE helps avoid trivial solutions, showing a $k^{-2}$ assessment floor at the usual learning scale. A leading-log frontier is characterized by an assessment exponent of $\min{\ell_k,2k\eta_k/U}$ in the magnitude-rich regime. This work specifies how the assessment target influences information requirements in causal experiments.

ChainLoRA: Geometry-Preserving Task Vector Merging for Continual Learning in LLMs

ChainLoRA is a replay-free continual learning framework designed for large language models by merging task vectors in a geometry-preserving manner. It formulates forgetting through a geometric view of task updates, separating directional overlap from coefficient coupling. The method combines chain-updated training with post-stream adaptive SVD merging for parameter integration. Procrustes adaptation aligns a shared carrier to the latest task, facilitating the geometric separation of task-specific components. Experiments demonstrate that ChainLoRA achieves state-of-the-art performance on benchmarks while managing parameter budgets effectively.

Fractional Laplace Neural Operators: Exact Architectures, an Expressivity Frontier at Criticality, and Certified Stability for Memory-Driven Network Dynamics

Fractional Laplace neural operators (fLNOs) are introduced to embed the memory structure found in hereditary network dynamics, which are described by Volterra resolvents. For commuting excitation-Laplacian pairs, a block graph-spectral layer exactly represents the linear Volterra solution operator. The expressivity frontier shows that finite rational realizations approximate fractional memory geometrically but cannot capture non-integer critical asymptotics. The framework allows for trainable parametrizations that enforce stability margins and separate genuine operator consistency from parameter sharing.

Block Optimism for Nonstationary Bandits with Latent Linear Dynamics

The study addresses a nonstationary stochastic bandit problem featuring latent linear dynamics where actions influence future state evolution and rewards are bilinear in the action and state. Previous methods achieve $\tilde{O}(T^{2/3})$ regret, but the authors propose an adaptive block-level optimism strategy. This involves approximating the infinite-memory reward process with a finite-memory proxy to facilitate planning. A UCB-based block algorithm is introduced to select blocks optimistically based on confidence sets for the truncated dynamics parameters. This approach yields a superior regret bound of $\tilde{O}(\sqrt{T})$ for this class of problems.
