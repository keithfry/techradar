Scientists combine EIT and pneumatic sensing for humanoid robot skin

Scientists have developed a hybrid robotic skin combining electrical impedance tomography and pneumatic pressure sensing to improve force detection across large areas of a humanoid robot. The system uses EIT to determine where contact occurs, while four sealed pneumatic pads provide an estimate of the force being applied. The researchers report a reduction in sensitivity variation, with the coefficient of variation falling from 0.31 to 0.14. The approach takes advantage of the different strengths of the two technologies, allowing EIT to provide spatial information while pneumatic sensing provides a net-force measurement.

FetchMan: Learning Visual Humanoid Loco-Manipulation Policies from Simulated Experiences

Researchers Omar Rayyan and colleagues developed FetchMan, a visual humanoid loco-manipulation policy that learns from simulated experiences and can generalize to novel scenes and objects. They replicate a "recipe" for learning from simulated data, first using behavioral cloning, then breaking through a performance ceiling with reinforcement learning. Refining the cloned policy with Flow-GRPO resulted in performance that synthetic behavior cloning couldn't match. FetchMan was evaluated on a simulation benchmark, deployed on a real humanoid robot, and extended to multi-object training.

Lambda-Hold Control: Human-Like Movement Emerges from a Minimal Task Reward in Predictive Musculoskeletal Simulation

A proposed controller, $\lambda$-hold control, enables a muscle-actuated skeletal model to learn human-like sprinting using only a minimal reward within an hour of training. The policy uses a per-muscle equilibrium-point threshold length $\lambda$ and a stretch-reflex recruitment law to compute muscle excitations automatically. This approach, grounded in physiology, sharpens the exploration through the proposed $\lambda$-hold controller, bringing together the equilibrium-point hypothesis, intermittent control, and optimal feedback control. The controller enables human-like movement in predictive musculoskeletal simulation.

Terrain-Aware Local Path Planning with Global DEM Data Integration for Autonomous UGV Navigation

This paper proposes a hybrid framework that integrates low-resolution Digital Elevation Model (DEM) data with real-time LiDAR-based obstacle detection and terrain analysis for efficient path planning in autonomous UGV navigation. A global path is initially computed using a preprocessed DEM-based A* algorithm, and local sensor data drives adaptive path correction to maintain safety and efficiency. The integration enhances path efficiency and terrain traversability, achieving a 95% obstacle avoidance rate and reducing the average encountered slope from $8^\circ$ to $2.7^\circ$ in custom terrain.

PDDL-ART: Autonomous Symbolic Abstraction From Demonstration For Long-Horizon Robotic Manipulation Using Vision-Language Models

PDDL-ART autonomously generates task-specific PDDL domain and problem descriptions from a single expert demonstration, natural language task description, and a library of high-level action names. The approach introduces a multi-stage correction pipeline operating at syntactic, semantic, and execution levels to ensure generated descriptions are semantically aligned. PDDL-ART achieves an average success rate of 93.3% on challenging manipulation tasks, compared to 78.3% for a baseline VLM-based planner.

Teach and Grow: An Agent-Centered Architecture for General Robot Learning

Teach-and-Grow Learning (TGL) is an agent-centered architecture for general robot learning, presenting a multimodal agent that turns successful demonstrations into reusable Skill Blocks. These blocks are composed, selected, and revised based on physical outcomes, storing executable behavior and structured Experience Memory. The LIBERO evaluation attains state-of-the-art performance, exposing skill induction, persistent reuse, and agent-directed adaptation. TGL treats deployment as a period of continued learning, where one task can make the next easier.

Robust Brachiation on a Life-Sized Dual-Arm Robot Using Waypoint-Guided Reinforcement Learning

Researchers developed a reinforcement learning-based method to enable brachiation on a life-sized dual-arm robot using Waypoint-Guided Reinforcement Learning (WGRL). The approach guides behavior acquisition by specifying waypoints for the end-effector trajectory while generating whole-body motion through reinforcement learning. The method achieves both forward progression and motion stability, and has been evaluated through Sim-to-Sim experiments and hardware experiments, confirming robust brachiation and failure recovery behavior.

arXiv - cs.RO

ORPA: Online Residual Policy Adaptation for Robot Manipulation Control with Human Feedback

ORPA, a framework for immediate, feedback-driven correction of robot actions, augments a pretrained control policy with a lightweight, feedback-conditioned module that predicts residual adjustments directly in joint space, allowing the system to adapt its behavior at runtime. This enables correcting robot actions without modifying the underlying policy parameters, addressing issues with traditional dataset aggregation and full-policy retraining. ORPA improves success rate and recovery from small perturbations compared to baseline control policies and rule-based inverse kinematics corrections. ORPA is evaluated on a set of precision-sensitive manipulation tasks using the ALOHA platform.

arXiv - cs.RO

Reconfiguration-Complete Motion Primitives with Constructive Planning for Deformable Planar Modular Robots

Researchers Jie Gu and colleagues introduce a new method for planning and reconfiguring motion primitives for deformable planar modular robots. They develop a square-cell abstraction that maps the robots' deformable geometry to a fixed-size grid, allowing for reversible and reconfigurable motion primitives. The new method proves that every non-straight edge-connected configuration with 7 or more modules can be transformed into a fixed canonical staircase, and provides a constructive planner that transports removable boundary modules while preserving connectivity. Experiments show the planner substantially reduces planning time.

arXiv - cs.RO

MANIGUARD: A Benchmark and Data Suite for Specification-Grounded Safety Evaluation and Improvement of Robotic Manipulation

MANIGUARD is a specification-grounded framework for evaluating and improving the safety of foundation-model manipulation policies. It comprises a benchmark task suite and a safety-annotated trajectory-generation pipeline, comprising 200 locked base tasks with safety specified independently of task success. The framework is tested on a Franka platform, with zero-shot and fine-tuned validation results showing that safety must be evaluated independently of task success, and fine-tuning raises safe task completion and engaged-and-safe behavior.
