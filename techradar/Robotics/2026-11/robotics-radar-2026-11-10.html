Robbyant Open-Sources LingBot-Touch, One Tactile Model for Three Sensor Types

Robbyant open-sourced LingBot-Touch, a tactile model that unifies signals from magnetic, visuotactile, and piezoresistive sensors into shared tactile tokens. This model was pretrained on nearly five thousand hours of touch recordings from human operators. Integrating these tokens into robot policies significantly increased success rates across various real-robot tasks compared to using raw sensor data. The research demonstrated that the tactile tokens provided substantial gains for models like LingBot-VLA and T-Rex. Limitations include testing only two hands and a focus on fingertip contact, as well as the exclusion of capacitive sensors from the pretraining data.

Make a Robot Arm Feel Weightless with NVIDIA Holoscan 5

NVIDIA Holoscan 5 enables low-latency robotic control and high-throughput perception through a unified programming model for CPU and GPU workloads. A gravity-compensation loop was demonstrated using three custom Holoscan operators to calculate inverse dynamics with Pinocchio and command a reBot arm. The framework uses execution partitions and drop-oldest queues to minimize latency and jitter in the control path. Profiling with Nsight Systems showed that pinning the control partition significantly reduced p99.99 latency for both C++ and Python implementations. This approach forms a foundation for building more complex systems like hand-guided teaching and manipulation.

How to minimize Wi-Fi roaming interruptions for autonomous mobile robots

Autonomous mobile robots require reliable, fast Wi-Fi roaming to maintain real-time connectivity while moving between coverage zones. Traditional Wi-Fi causes interruptions because the main radio must stop traffic to search for new access points, leading to latency and packet loss. A dedicated scanning architecture, like Synaptics Scan Core, separates network discovery from application traffic using a low-power subsystem. This separation allows for faster roaming decisions, lower latency, and improved power efficiency. Implementing dedicated scanning enhances mobile robot performance by enabling continuous network awareness and faster transitions.
