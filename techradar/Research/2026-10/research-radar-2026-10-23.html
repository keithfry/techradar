A Small Model Asks Better: Fine-Tuning Query Clarification for Retrieval-Augmented Generation

Query clarification is necessary in Retrieval-Augmented Generation (RAG) systems when user queries are ambiguous or contextually unclear. The study addresses scenarios where queries are ill-formed or have multiple relevant interpretations based on retrieved documents. A new dataset, ClariEdge, containing ambiguous and non-ambiguous queries is introduced for this task. A lightweight fine-tuned LoRA model achieves high classification accuracy, outperforming larger models in clarifying query quality. Hard negative examples are shown to be crucial for distinguishing truly ambiguous queries from those that are merely contextually complex.

Scaling in Games: Continued Pre-Training For Embodied Agents In Diverse Virtual Worlds

Continued pre-training across data volume, diversity, and model size was investigated for embodied agents in diverse virtual worlds. Results indicated that more data improves in-corpus performance, diversity helps transfer to related worlds, and model size affects data efficiency and generalization to distant worlds. An early interface phase followed by a later world phase was observed, aligning with an empirical scaling law for validation loss. Models proved competitive in 3D settings, yet limitations in imitation suggest further training stages are necessary for generalist agents.

SpecEvo: Speculative Evolution with Large Language Models for Cost-Efficient Scientific Discovery

SpecEvo is a multi-LLM framework designed for cost-efficient scientific discovery by coordinating lightweight and frontier models. It uses lightweight models for parallel speculation and evidence consolidation, while frontier models intervene strategically at sparse checkpoints. This workflow delegates routine exploration to inexpensive models, reserving high-level reasoning for crucial interventions. Results show SpecEvo outperforms baselines while reducing API costs by up to 80% across various discovery tasks. The method demonstrates effective trajectory-conditioned model coordination for efficient scientific exploration.

Automating ML for Science: Can Frontier Agents Climb Scientific Hills in the Wild?

Frontier coding agents are tested on the demanding task of improving published scientific models, which requires domain insight beyond standard ML engineering. Agent4Sci is introduced as a long-horizon testbed to measure the extent to which these agents can advance scientific ML benchmarks in real-world conditions. Empirically, agents achieved relative improvements by using engineering tricks rather than deep research insight. Trajectory analysis revealed limitations such as novelty miscalibration, resource under-utilization, and rapid regression to local engineering sweeps. The work proposes lightweight plug-in skills to bridge the gap between ML engineering and domain insight for these agents.

Forging More Tasks into Better Harnesses: Agentic Harness Evolution via Successive Scale Racing

Agentic harness evolution uses task execution experiences to optimize an agent's instructions and tools. A failure mode emerges where expanding the task pool causes existing methods to degrade due to suboptimal evidence selection. Successive Scale Racing (SSR) is proposed to address this by adaptively searching for optimal evidence combinations in each evolution round. SSR races candidate harnesses based on task quality and coverage within a limited compute budget. Empirically, SSR achieved state-of-the-art results across benchmarks while improving performance as the task pool increased.

Speedrunning Relational Foundation Model Pretraining

Relational foundation model pretraining is decentralized through speedrunning leaderboards to overcome barriers in accessing private training recipes. The work introduces modded-nanoRT, a leaderboard for Relational Transformers, which fixes the benchmark by calibrating the selection based on learning curve separation. The method utilizes a relational operator, typed trilinear attention, along with Muon and SIGReg. The resulting recipe achieves a target in 305.63 seconds on one GPU, significantly faster than the reference. The authors plan to release the benchmark, frozen artifacts, and record runs for public use.

To Manipulate or Not: Opinion Dynamics in LLM Interactions

The research introduces a controlled LLM-LLM debate framework to study opinion dynamics in extended conversations. Two language models, GPT-6 Luna and Gemini 2.5 Flash Lite, are used to discuss climate-change attribution, with one model assigned a stance and the other not. Opinion dynamics varied based on model combinations, as same-model interactions narrowed the opinion gap while cross-model interactions widened it. Explicit reports and in-dialogue behavior reveal different aspects of this dynamic, and a simple persuasion instruction was not consistently effective. These findings indicate that conversational influence depends on the participating models, not just assigned roles and initial positions.

MoEZip: Routing-Aware KV Cache Compression for Sparse Mixture-of-Experts LLMs

MoEZip is a method for routing-aware KV cache compression specifically for sparse Mixture-of-Experts (MoE) language models. It addresses the issue that standard compression methods neglect how KV cache eviction affects expert routing, which can degrade generation quality. The method introduces a novel metric based on the Fisher information matrix of routing distributions combined with attention weights for context scoring. MoEZip integrates complementary scoring systems to handle both dense and sparse MoE architectures effectively. Experiments demonstrate that MoEZip significantly outperforms the state-of-the-art by improving scores on LongBench and RULER benchmarks under aggressive cache compression.

Spectral Uncertainty Decomposition for Sparse Bayesian Learning

Estimating neural sources from M/EEG measurements is an ill-posed inverse problem where uncertainty quantification is challenging. The proposed spectral framework uses the singular value structure of the prior-preconditioned forward operator to decompose the posterior covariance. This decomposition separates uncertainty into data-informed and fundamentally irreducible epistemic components. A subtractive decomposition is also derived, expressing the prior covariance as a sum of posterior and data-driven reduction terms. These methods provide interpretable uncertainty quantification for linear-Gaussian Bayesian inverse solvers in M/EEG source imaging.

Prediction Is Not Calibration: Item Parameter Recovery and Representation Coupling in Knowledge Tracing

Predictive accuracy in knowledge tracing models does not guarantee the recovery of item parameters. The study investigates item parameter recovery and representation coupling using various item response decoders and encoders. Findings indicate that while difficulty and mean threshold recovery is robust, discrimination and option slope recovery depend heavily on the scale and spread of estimated ability. Separating the sequence representation from the item parameter key improves recovery and cross-order consistency without sacrificing test accuracy. Ultimately, item parameters like discrimination must be evaluated separately from response prediction.

Learned multimodal representations for health records are often trained for reconstruction, which may not suffice for causal identification. The study examines counterfactual outcomes and interventional effects under exposure-induced confounding using these representations. How Prompt Style Affects AI Accuracy and Speed in Competitive Programming

Exploratory study of prompt styles on GPT-5.5 across tasks from the International Olympiad in Informatics and NP-hard speed tasks was conducted. No single prompt style was found to be optimal, as the best style depended on the specific task and result summarization method. Differences in accuracy stemmed from outlier runs, indicating that single metrics can obscure the true effect of prompting. Comparing results to human contestants showed the AI was neither strictly better nor worse than humans across all tasks. Extending the comparison to runtime speed and human performance provides a more comprehensive view of prompt style's impact.

Edit, Don't Imitate: Minimal-Edit On-Policy Distillation for Multimodal Reasoning

Visual mathematical reasoning can suffer from errors when a vision-language model misreads diagrams, creating false premises for reasoning. The proposed method uses minimal-edit on-policy distillation to correct these errors using reference descriptions and solutions as training information. A teacher scores incorrect student outputs based on a minimal-edit objective, focusing loss only on teacher-disfavored tokens. Correct rollouts are reinforced with task-reward reinforcement learning, preserving on-policy supervision without full imitation. This technique improves perception-oriented performance and transfers to external mathematics benchmarks.

Why Constrained Updates Still Forget: A Functional-Path Analysis of Continual SFT

Supervised fine-tuning can disrupt previously acquired behavior, and existing constraints do not clearly explain the relationship between protected objects, trajectories, and retained outputs. The research introduces a functional-path account to decompose old-loss changes during updates into controlled directions, gradient staleness, probe mismatch, and finite-step effects. This account identifies a conditional refresh budget and the restoring direction provided by informative replay. Different constraint placements and granularities impact retention differently across code-label audits and checkpointed generation. The findings suggest mitigating forgetting requires explicit functional anchors and joint auditing of old and new data.

Differentially Private Synthetic Data via Generalized Moment Matching

The research introduces a method for generating differentially private synthetic data for databases in the $[-1,1]^d$ space under an integral probability metric. Generalized moment matching is utilized to privately estimate moments, fit a probability measure, and sample synthetic records. A general error theorem connects moment error to the target IPM, extending Chebyshev moment matching for 1-Wasserstein distance. The framework applies to objectives like maximum mean discrepancy and provides guarantees for sliced Wasserstein-1 distances. These methods yield minimax optimal rates for fixed dimensions when sufficient synthetic data is available.

Flow-based Spectral Kernel Learning for Nonstationary Attention

Flow-based spectral kernel attention (FSKA) is proposed as a framework for learning expressive, nonstationary attention kernels. It achieves this by formulating kernelized attention through spectral density learning and parameterizing the spectral density using normalizing flows. This design allows for flexible and regularizable kernel learning compatible with scalable linear-attention computation. FSKA simplifies attention design by removing query-key and fixed orthogonal value projections, leading to a more parameter-efficient architecture. Experimental results show FSKA achieves competitive or improved performance while reducing trainable parameters by $40\%$--$47\%$.

xVGAE: A Hierarchical Variational Graph Autoencoder for Exchangeable Graphs

The xVGAE is a Hierarchical Variational Graph Autoencoder designed for exchangeable graphs. It is inspired by the Aldous-Hoover theorem, which characterizes graph distributions invariant to node permutations. The model learns an approximation of graphons and latent variables from a training set of graphs. xVGAE can generate new graphs quickly that closely match the statistics of the training data. This approach enables fast and high-quality graph generation for applications where standard models face computational limitations.

Continuous-depth Deep Gaussian Processes

Deep Gaussian Processes are proposed with a continuous-depth formulation to address optimization difficulties in discrete-depth models. This formulation treats depth as a continuous evolution governed by a stochastic differential equation with a GP-based prior on the drift family. Two instantiations are studied: CDGP, which has a direct GP prior over the state-depth drift, and FlowDGP, which uses a flow-evolved prior for richer depth dependence. The research analyzes the sensitivity of the single-sample DGP objective and evaluates performance on various regression tasks. Experiments indicate that residual DGP improves upon plain DGP, while CDGP and FlowDGP offer superior results.

Random Projections for Spectral Algorithms: Optimal Rates in Sobolev Norms

Random projections effectively reduce computational overhead in spectral algorithms while preserving data structure. The paper establishes optimal learning rates in Sobolev norms for these Random Projection (RP)-based methods under general conditions. Using RKHS embedding and operator similarity analysis, the authors find the required projection dimension is proportional to the effective dimension. This optimality holds across a wide range of source conditions without relying on uniform boundedness assumptions. Experimental results confirm the theoretical validity and practical effectiveness of these projection methods.

Prediction Uncertainty Controlled Computer Model Calibration

A two-layer framework is proposed to control prediction uncertainty in computer model calibration. The first layer uses a conditional flow-matching model to learn an amortized posterior for calibration parameters based on perturbed simulator outputs. The second layer employs conformal risk control to arrange posterior draws into nested sets, selecting the smallest set whose pointwise bands achieve a target miscoverage. This method controls expected miscoverage in finite samples, showing sharper bands than prior methods for a benchmark. Application to an age-structured SEIR model demonstrated that the resulting uncertainty bands exposed structural model inadequacies.

Metric Conformal Prediction via the Conditional Expected Local Radius

The method introduces the conditional expected local radius (CELR) to facilitate metric conformal prediction in general metric spaces. CELR quantifies local conditional probability concentration, enabling prediction sets that handle heterogeneity without requiring density or vector space structures. A novel conformal prediction method is developed using this measure, which yields a nonconformity score comparable across covariate values. The approach adapts a metric distributional random forest to manage multivariate covariates and nonlinear interactions efficiently. Numerical studies confirm the method's effectiveness in uncertainty quantification and computational savings compared to other scoring methods.
