Your Robot’s Safety Functions Already Work. What If the Input Lies?

Robot safety functions rely on inputs like distance readings or stop signals, which can be deliberately manipulated to cause unintended behavior. Research shows that adversarial inputs, such as altered images or audio, can change a robot's actions despite protective systems being in place. This manipulation challenges safety assessments that often only consider accidental faults, necessitating a focus on deliberate cyber attacks. Safety teams must investigate the source and integrity of all information used by safeguards to ensure they remain effective. Strengthening safety requires testing against manipulated inputs and continuously updating evidence throughout the robot's lifecycle.

Bounded-Fidelity Sim-as-Demo-Stage: Mocap Handoff for Governance Benchmarks

The research addresses the issue of contact force integration noise in simulators, which creates divergence in audit-chain logs for LLM-driven robots during object handoffs. The authors propose bounded-fidelity sim-as-demo-stage, a pattern that suppresses contact physics within defined handoff envelopes while maintaining full dynamics elsewhere. This method uses a MuJoCo mocap primitive driven by a Python adapter to achieve this control over simulation fidelity. Experiments show that by controlling envelope-edge timing jitter, audit chain reproducibility is achieved with near-zero engineering cost. This pattern allows benchmark designers to ensure audit-chain stability in simulations without incurring high fidelity costs.

Multi-Reference Path Tracking Control for an Agricultural Tractor with Nonlinear Model Predictive Control

A path tracking controller based on Nonlinear Model Predictive Control (NMPC) is developed for guiding agricultural tractors along a predefined path. The NMPC objective function incorporates multiple segments of a piecewise-linear reference path. Methods are also presented for selecting the most viable reference segments from the full path. Field tests demonstrated that the NMPC solver converged quickly and achieved a mean absolute cross-track error of 6.1 cm while tracking the curved path.

Probabilistic Plan Legibility with Off-the-shelf Planners

The paper proposes a method for legible planning in arbitrary PDDL domains by extending prior research on planning legibility. It avoids the need to construct ad-hoc planners by focusing on planning with off-the-shelf planners. The method incorporates a second-order theory of mind to estimate the observer's perspective, which helps in understanding goal disambiguation. Legibility is shown to be a trade-off with plan efficiency, requiring a regularizing factor for optimal balance. This approach has potential applications in human-robot teaming scenarios.

arXiv - cs.RO

HumanoidTTT: Test-Time Capability Reuse for Efficient Humanoid Control

HumanoidTTT is a framework designed for test-time capability reuse in continual humanoid control to improve efficiency. It introduces Selective Full-Motion Reuse to allow direct reuse of complete motions from certified entry states, bypassing fresh generation. Test-Time Capability Consolidation adapts which qualified capabilities are retained in a store based on subsequent deployment reuse feedback. Experiments showed zero unsafe accepts and a 16.4$\times$ speedup over fresh generation. This method also improved avoided generator calls by 13.2 per 200 requests compared to a frozen counterpart.

arXiv - cs.RO

Real-Time Whole-Body Safe Motion Generation for Multi-Segment Tendon-Driven Continuum Robots

The paper proposes a unified actuation-space framework for real-time, safe motion generation in multi-segment tendon-driven continuum robots. It utilizes an energy-based variable-curvature model to account for non-uniform bending and provides analytical Jacobians for kinematic calculations. A multipoint Control Barrier Function-Quadratic Programming (CBF-QP) enforces backbone clearance and respects actuation limits to ensure collision avoidance. Experiments showed a 96% collision-free success rate in static scenarios and 100% in dynamic ones, demonstrating real-time performance of 6.66 ms.

arXiv - cs.RO

DriftOPD: Sequence-Level Reverse-KL Distillation for One-Step VLA Policies

DriftOPD is a teacher-free, rollout-free framework for sequence-level on-policy distillation of continuous Vision-Language-Action (VLA) action experts. It decomposes the sequence-level reverse Kullback-Leibler divergence into a chunk-level term and a future-potential term reflecting long-horizon effects. The framework optimizes these terms using a one-step drifting objective and a Q-function critic learned from offline demonstrations. This allows for sequence-level optimization using only offline data and one-step action generation. DriftOPD achieves performance comparable to multi-step teacher policies in various VLA architectures.

arXiv - cs.RO

IndoorBEV: A Lightweight Real-Time LiDAR BEV Perception System for Indoor Mobile Robots

IndoorBEV is a lightweight framework for real-time LiDAR perception in indoor mobile robots by using a height-aware Bird's-Eye-View (BEV) representation. It mitigates the loss of vertical geometric information by summarizing vertical point distribution using statistical height features and multi-frequency height encoding. The system employs a lightweight encoder to integrate geometric and local features to produce semantic BEV maps and object bounding boxes. IndoorBEV has a small parameter count of 0.6M and achieves low latency of 169.6 ms on target hardware. Evaluations confirm a favorable balance between perception accuracy, speed, and memory consumption.

DexPolicy: Scheduled Exploration for Trajectory-Guided Dexterous Manipulation

DexPolicy introduces scheduled exploration to guide trajectory-guided dexterous manipulation by explicitly controlling the exploration scale during training. It anneals the exploration from broad to narrow as training progresses while keeping other parameters fixed. Experiments across different policy-optimization settings, including PPO, GRPO, and FPO, showed improvements in deterministic target success. Specifically, the FPO method achieved a higher mean target success than linear decay in some evaluations. The study concludes that schedules should be judged by terminal task success under intended execution conditions.
