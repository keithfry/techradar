CHOREO: Every Humanoid Skill as a Trajectory

Recent advances in humanoid robotics have produced diverse skills, but they remain siloed due to incompatible representations. CHOREO is a framework for training-free composition of heterogeneous humanoid skills by viewing every skill as an executable motion trajectory. It introduces SkillMotion, a unified representation combining motion states, contacts, semantics, and boundary conditions for each capability. Skills can be composed using direct continuation, blending, or bridge motions without retraining source models. Experiments on Unitree G1 showed that organizing SkillMotion assets achieved high success rates across multi-action tasks.

D3DWA: Adaptive Weight and Prediction-Horizon for Dynamic Window Approach via Dueling Double Deep Q-Network

The D3DWA framework is enhanced by D3DWA, which adapts the Dynamic Window Approach using a Dueling Double Deep Q-Network. This adaptation allows the system to jointly select evaluation weights and a prediction horizon based on the current navigation state. Longer prediction horizons are suitable for open areas, while shorter ones are better for cluttered regions. Experiments in simulated environments and real-robot tests demonstrated that D3DWA successfully navigated various layouts. The results confirm the benefit of adaptively managing evaluation weights and prediction horizons.

DeViGrasp: Robust Visual Mobile Grasping for Quadruped Manipulators under Degraded Perception

Quadruped manipulators struggle with whole-body control when visual perception is degraded by factors like occlusion and noise. DeViGrasp introduces DeViGrasp-Bench, a benchmark to systematically evaluate grasping under these visual degradations. The method proposes DeViGrasp-Net, a teacher-student framework combining grasp reasoning with reliability-aware temporal target estimation. This framework leverages dual-view segmented-depth data and memory mechanisms to improve performance under difficult conditions. DeViGrasp-Net significantly outperforms existing methods like VBC and DQ-Net across various degradation levels.

ORDER: A Fictitious-World Benchmark for Domain-Adaptive Embodied AI

ORDER introduces a benchmark based on a fictitious world to evaluate Domain-Adaptive Embodied AI. It uses a synthetic corpus defining self-consistent physics that is absent from pre-training data. The benchmark includes a knowledge test and a compositional task for safe manipulation across familiar and novel scenes. Models that continually pre-train show genuine world-model induction, unlike memorization. Performance on the spatial task, not just knowledge testing, predicts real plan quality in embodied systems.

OJOx: Specification-Conditioned Demonstrations for Embodied AI in Construction

Large-scale human demonstrations often lack the external specifications that define an action's purpose. OJOx introduces specification-conditioned demonstrations for embodied AI in construction by synchronizing perceived physical states, external design specifications, and the demonstrator's behavior. This system uses a capture interface to deliver design geometry to a headset and record it synchronously with whole-body and hand motions. The work presents a method for training embodied policies to act toward specifications not present in their training experience. Recorded sessions remain compatible with existing humanoid retargeting infrastructure for simulation and testing.

When Does Test-Time Physical Diagnosis Pay? A Frozen Policy Buys Evidence It Never Reads

To effectively use test-time physical diagnosis for robot behavior, six ordered empirical conditions must be met. These conditions involve a meaningful reference, identifiability, evidence use, decision value, selection value, and safe realization. While these conditions hold in controlled environments, the process breaks down when transferred to unseen mechanisms concerning evidence use. A linear model based on trace increments can recover correct choices, indicating the trace is informative but unused. Therefore, successful physical identification does not guarantee useful adaptation; evaluation must pinpoint where the diagnostic chain fails.

arXiv - cs.RO

EditWM: Event-Decomposed World Modeling with Incremental Correction for End-to-End Autonomous Driving

EditWM proposes a world model for autonomous driving by decomposing future predictions into normal evolution and event-induced incremental corrections. It uses a trajectory-conditioned normal predictor, which is then refined by a correction decoder that generates bounded feature updates based on observation history. This correction is regulated by a learned gate, and the corrected features inform trajectory scoring via cross-attention. Evaluation on navtest scenes showed a 5.35% reduction in future-feature MSE and improved trajectory selection. The system achieved a high EPDMS score, demonstrating improved prediction and planning.

arXiv - cs.RO

Embedding Physics Priors in Robot Learning: A Survey

Physics-embedded robot learning integrates physical laws and constraints into learning algorithms to address robotics limitations. Physics priors offer robotics-specific inductive biases that can improve generalization, interpretability, and sample efficiency beyond purely data-driven methods. The survey reviews various approaches, including physics-guided inputs, model architectures, and loss functions, across different machine learning models. It covers applications such as dynamics learning, planning, prediction, control, and estimation, along with the associated software ecosystem. The work concludes that physics priors complement data-driven learning, fostering more generalizable and trustworthy robotic systems.

AffordanceWAM: Affordance-Aware Joint World-Action Modeling for Robot Manipulation

AffordanceWAM is a generative World Action Model designed for robot manipulation by representing object-centric spatiotemporal affordances. It uses Scalar Affordance and Affordance Heatmaps to ground visual prediction in task-relevant objects and interaction regions. The model is built upon a pretrained video diffusion Transformer and employs separate World and Action Experts connected by Masked Joint Self-Attention. It jointly predicts future RGB observations, affordance fields, heatmaps, and continuous robot actions using a unified flow-matching objective. Experiments show AffordanceWAM provides performance gains over baselines in robot manipulation tasks.
