ROS Discourse General: Resetting/Clearing a message without reallocating?

The author seeks feedback on how to clear or reset a message in performance-sensitive C++ code without reallocating memory. The goal is to make the code behave as if a new message is created each time, while avoiding the overhead of full recreation. Current options involve either reusing a message, which risks stale data, or creating a new message, which frees memory. The author proposes that the code generation for C++ messages should include a method to clear all lists, recursively clear sub-messages, and reset other types to their defaults.

What industrial drone deployments reveal about real-world autonomy challenges

Autonomous drone performance in industrial settings is challenged by the simultaneous interaction of various subsystem uncertainties, as environmental disturbances cause multiple sensors to fail concurrently. Reliable deployment requires engineers to understand how uncertainty propagates across localization, perception, planning, control, and data acquisition. Industrial environments introduce complex issues like signal obstruction, reflective surfaces, and dynamic obstacles that defy simple laboratory testing. Therefore, practical validation demands defining measurable acceptance criteria that test system interactions rather than isolated performance. Ultimately, reliable autonomy is a system-level property achieved by ensuring all components, including human supervision, are validated together.

Inhabitant: An Agent Framework for Long-Horizon Human-Scene Interaction with Spatial Control and Quantitative Feedback

Inhabitant is a training-free agent framework designed for long-horizon human-scene interaction with spatial control and quantitative feedback. The agent specifies motions via positions, paths, and poses, measures deviations from intent, and revises its control specification accordingly. The framework is evaluated on Inhabit, a benchmark involving 75 household tasks in various furniture layouts. Results show Inhabitant successfully completes 98.7% of tasks with Claude Opus 5.5. Ablation studies confirm that both spatial control and quantitative feedback are crucial for successful execution.

arXiv - cs.RO

Mapping the Wind to Find the Source: Online Physics-Informed Gas Source Localization with Mobile Robots

Gas Source Localization with mobile robots is addressed by a physics-informed probabilistic framework to handle sparse and noisy wind and gas measurements. The system continuously reconstructs the spatially varying airflow field as the robot moves and uses a forward dispersion model to predict gas patterns from candidate source locations. These predictions are compared with measurements to iteratively update a probabilistic belief about the source location. The framework accounts for the spatially non-uniform reliability of the estimated wind field, which improves localization robustness. This method enables informative path planning to efficiently guide the robot toward relevant areas for source localization.

MAWAM: A Multi-Agent World-Action Model for Coordinated Manipulation

MAWAM is a multi-agent world-action model designed for coordinated manipulation where team actions affect the shared environment. It jointly generates future views and executable action chunks for all robots in a single sample. The model utilizes cross-agent attention to denoise action and future-view tokens while maintaining separate control interfaces for each robot. MAWAM achieves high success rates on real-robot tasks, notably outperforming MA-VLA demonstrations. Simulation results show MAWAM reaching 90.3% mean success on eight tasks with teams up to four arms.

arXiv - cs.RO

From Self-Play RL to Constrained Control: Distilling DiffMPC Students with DAgger

Self-play reinforcement learning yields strong policies, but they lack verifiability, and Differentiable Model Predictive Control (DiffMPC) can enforce constraints. The method replaces a policy's action head with a DiffMPC to enforce road boundaries and agent ellipses on a PPO teacher's backbone. DAgger is used to distill this constrained knowledge to a smaller student model within the teacher's self-play simulator. The resulting student model achieves comparable performance across different environments while significantly reducing training time.

arXiv - cs.RO

VG-Steer: Visual-Geometric Policy Steering from In-Context Aligned Abstractions

VG-Steer corrects robot policies by transferring motion from successful in-distribution rollouts along object-relational distance pairs. This steering signal is derived by combining semantic understanding from Large Vision Models and Vision-Language Models. The method uses these combined inputs to generate a visual-geometric guidance signal for policy adaptation. In simulation, it effectively corrects flow-matching policies under pose and task-goal shifts. Experimentally, it increased the workspace coverage and success rate for cable placements on real robots by extending beyond training positions.

arXiv - cs.RO

Bridging vision-language reasoning and learned control for legged navigation in the wild

ROAM is a system designed for legged robots to achieve kilometer-scale navigation in complex real-world environments. It integrates world knowledge from a Vision-Language Model (VLM) with locomotion and planning policies learned through reinforcement learning. The VLM provides semantic reasoning for interpreting the scene and assessing risks, which conditions the low-level policies. An open-vocabulary segmentation module translates these semantic labels into a real-time risk map for navigation. Experiments demonstrated the system's capability to autonomously navigate challenging terrains while interpreting environmental cues.

arXiv - cs.RO

Ferrofluid Shape Control with Deep Reinforcement Learning

Ferrofluids, which contain magnetic nanoparticles, can be shaped using external magnetic fields, making them useful as soft robotic bodies. Controlling these shapes is challenging due to the fluid's nonlinear continuum dynamics. The research employs deep model-based reinforcement learning to control transient shapes not sustainable at equilibrium. Policies are learned by interacting directly with the physical system, selecting commands for a single electromagnet based on visual observations. This method successfully guides the ferrofluid to achieve various geometries like polygons, asterisks, and pentominoes.
