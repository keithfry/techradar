New ISO standard enables mobile robots from different vendors to work together

A3 has published ISO 21423:2026, a new international standard for communication and interoperability among industrial mobile robots. This standard establishes common communication requirements for mobile robots from different vendors operating in the same facility. It specifies how robots, fleet managers, and other equipment can exchange information such as location, status, and tasking. Adopting this standard is expected to reduce path interference, improve system efficiency, and foster market competition. Furthermore, the standard covers communication with external systems like ERP tools and building automation.

Muscle coordination can be mimicked by electric motors – it could lead to improved robots

Electric motors were used to build a physical model simulating muscle coordination. The model demonstrated that muscle-like behavior emerges from the physical arrangement of motors and their shared mechanical structure, not from continuous programming. This setup showed that motors can coordinate by briefly engaging a shared backbone, allowing forces to be transmitted collectively. This principle of coordination without a central conductor could lead to simpler and more adaptable designs for robots. These findings suggest a path toward creating more organic and adaptive robotic systems.

ROS Discourse General: Intrinsic Core released: Open-source, ROS-compatible real-time control, motion planning and more

Intrinsic Core was released as an open-source, ROS-compatible real-time control framework for industrial robotics. It provides a hardware-agnostic runtime, SDK, and framework for real-time control, motion planning, and grasp planning. The release includes a pre-configured setup, including simulation tools and a reference solution called the Open Machine Tending Solution (OMTS). Community members are actively building variations on OMTS, demonstrating its practical application in tasks like picking up and inserting objects. Intrinsic Core aims to be practical and open by fostering community collaboration.

Opinion: What happens when the robot is wrong?

Increased robot speed necessitates a clear process for experienced operators to challenge machine decisions to prevent errors from spreading. Safety procedures must remain paramount, and challenges should not supersede physical safeguarding measures like emergency stops. Effective commissioning should include rehearsals involving false positives and conflicting instructions to test human response and decision-making authority. Systems must retain exception records detailing operator challenges, evidence, and responses across shifts. Ultimately, a successful system evaluation should include metrics for human-AI teaming and operator understanding alongside traditional performance measures.
