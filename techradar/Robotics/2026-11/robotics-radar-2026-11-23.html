One Behavior, Out of Order: Deterministic Execution and Parallel Simulation of ROS 2 Applications

ROS 2 applications suffer from nondeterminism due to asynchronous communication, making tests unreliable. A coordination scheme is introduced to make ROS 2 applications deterministic by enforcing predefined read and write time instants for all components. An out-of-order parallel simulation algorithm is then developed to speed up testing based on these time instants. This method is implemented in a simulator that runs existing ROS 2 applications without modification. The simulation proves to be significantly faster and more memory-efficient than other parallel simulation methods.

arXiv - cs.RO

Latent Space Planning with Sequential Monte Carlo

Planning with learned world models involves finding action sequences that achieve a goal, where sampling-based methods and gradient-based methods face limitations. Sequential Monte Carlo (SMC) is utilized to naturally evolve a sequence of intermediate distributions in this context through importance weighting and resampling. The method formulates latent-space planning as optimization guided by SMC, where a gradient-based optimizer refines the plan. This approach outperforms other methods on navigation and manipulation tasks by significantly improving the success rate.

arXiv - cs.RO

FORTH: Grounding Tactile VLA Execution via Forward-Only Proxy-Control Pairing

Vision-Language-Action (VLA) policies assume proxy loss minimization grounds tactile execution, but this assumption fails due to mismatches at different deployment levels. FORTH introduces a forward-only measurement harness to explicitly pair optimization objectives with physical control observables. It incorporates a tactile encoder, a zeroth-order adapter, and a SlipGuard gate to achieve grounded execution. This method results in superior performance, achieving a 97.6% success rate and reducing activation memory significantly compared to backpropagated methods. Ultimately, FORTH enhances physical intelligence by enabling deeper perception.

arXiv - cs.RO

MomentMem: Memorizing Key Moments for Robot Manipulation

Visual moment memory focuses on retaining key visual details from specific moments to aid robot manipulation. MomentMem proposes a hierarchical architecture where a Vision-Language Model selects keyframes and an executor predicts actions based on these memories. This separation allows for evaluating memory selection independently of action execution. MomentMem achieved 49.9% success on the VMBench tasks, outperforming baselines by a significant margin. The method demonstrates the value of retaining sparse visual evidence for memory-dependent robotic tasks.

arXiv - cs.RO

Search-Informed MPPI for Kinodynamic Motion Planning via Monte Carlo Tree Expansion

Kinodynamic motion planning in cluttered environments is challenging due to the need for dynamically feasible, collision-free trajectories over long horizons. Search-Informed MPPI (SI-MPPI) is proposed as a framework to combine Model Predictive Path Integral (MPPI) optimization with Monte Carlo Tree Search (MCTS) for this task. It fuses MCTS expansion and default-policy simulation into an MPPI expansion guided by "baits" for GPU-batched trajectory optimization. Feasibility gating and cost-based backpropagation are used to guide sparse tree growth in the MCTS process. Simulations show SI-MPPI produces smoother control profiles and smaller search trees than baselines while maintaining competitive planning performance.

arXiv - cs.RO

TacHOI: Contact-Aware Object Reconstruction and Tracking for Egocentric Videos

TacHOI is a training-free framework that reconstructs and tracks objects in egocentric videos by integrating tactile contact with monocular vision. It uses tactile contact to constrain object depth relative to the hand, leveraging spatially separated contacts on the hand as a physical ruler for object extent. The method jointly optimizes hand poses, object trajectories, and anisotropic object scale alongside visual alignment. Experiments on ARCTIC and HO3D sequences showed significant error reduction, achieving 3.6 cm and 2.8 cm errors respectively. This approach demonstrates applicability when measured tactile observations are available.

arXiv - cs.RO

LoCo-WAM: Test-Time Training as Long Context for World-Action Models

LoCo-WAM introduces test-time training to use longer context for world-action models by learning from action outcomes without expert labels. It updates a low-rank adapter in the video expert using newly observed frames while maintaining the original short history length. These updates accumulate within episodes and reset between them, allowing past observations to influence decisions outside the input window. Experiments demonstrate that this method improves task success across simulation benchmarks. The learned updates enhance prediction of future frames and actions, with their effect on actions increasing as the episode progresses.
