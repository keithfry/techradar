Structured Authority Injection: Persistent Human Control for LLM Agents via Typed MCP Overrides

Structured Authority Injection (SAI) is a protocol designed to give human operators persistent control over LLM agents. It achieves this by routing human corrections through typed, schema-validated Model Context Protocol (MCP) tool calls. SAI introduces three override classes—Constraint, Priority, and Strategy—with defined persistence semantics and an enforced precedence order. This method allows for explicit and persistent human control without requiring model fine-tuning. Evaluation showed reduced ambiguity in directive interpretation and mitigated authority decay during agent planning.

Rethinking User Encoders: Routing Diffusion States for Scenario-Adaptive User Representation

Existing user encoders serialize behavioral logs into static representations, which limits bidirectional information flow and hinders cross-modal interactions. The proposed FINDERS framework uses the iterative denoising process of diffusion language models as a multi-granularity reconstruction space. It introduces learnable meta-slots to organize denoising states into transferable cross-modal semantics and modality-specific factors. A lightweight router dynamically emphasizes relevant slot directions based on scenario queries to guide cross-source fusion. Experiments show FINDERS consistently outperforms other methods across various industrial scenarios.

The Event Reasoning System (ERS) uses an explicit event graph to represent reasoning states. Low-level rules facilitate local transformations, and high-level rules hierarchically compose subgoals and paths. Experiments show that this approach can significantly reduce inference time compared to single-level global control.

ECHOES: Seeing Beyond the Current Image via Recursive History Compression and Privileged On-Policy Distillation

ECHOES proposes a method to improve long-horizon GUI agent reasoning by compressing visual history using recursive history compression and privileged on-policy distillation. The approach uses a Compression-Think-Action (CTA) format to recursively update a textual history state. A teacher model provides dense token-level distillation on student rollouts, guided by a Perception-Memory Fidelity (PMF) Gap-guided On-Policy Distillation (OPD-RL) framework. The research introduces ECHOESBMK, a benchmark to evaluate visual perception and state retention. Experiments show that ECHOES achieves competitive performance with better inference cost and zero-shot transfer to new visual planning tasks without retaining historical screenshots.

PRIME: Towards Verifiable Evidence-Grounded Reasoning in LLM Agents

PRIME introduces Precommitted Rules for Inference from Minimal Evidence to enable verifiable evidence-grounded reasoning in LLM agents. It mandates fixing evidence routes before checking to specify how each conclusion can be justified. A separate program records check results and rejects conclusions that lack justification based on these rules. PRIME guides agents to the strongest supported conclusions by pointing to or running necessary checks. Experimentation showed that PRIME significantly reduced unjustified conclusions and improved the quality of agent reasoning.

From Natural Language Intent to Executable Control: Hierarchical Feedback-Guided LLM Planning for Multi-component Cyber-Physical Systems

Large language models (LLMs) can translate natural language into task plans for cyber-physical systems, but existing methods struggle with plan feasibility and lack informative failure feedback. A hierarchical feedback framework is proposed to guide LLMs in generating executable plans for these systems. This framework involves prompting LLMs for both task plans and signal temporal logic constraints, and uses an algorithm to detect contradictions between them. When execution fails, diagnostic information is extracted and fed back to guide task replanning. Experiments demonstrated that this approach achieves an 87.9% success rate in generating executable plans for heterogeneous CPS scenarios using GPT-5.

L-SplineFNO is a memory-efficient neural operator that combines a Fourier neural operator backbone with a sparse, learnable B-spline transfer for unstructured meshes. The research designs region-inhomogeneous forward dynamics to address trust issues in discrete diffusion models. It combines absorbing and uniform-mixing kernels with region-dependent rates to expose the model to uncertain tokens during training. Rank Measures of Fine-Tuning Updates Need a Noise Baseline

Studies of fine-tuning weight updates often use rank measures but require a noise baseline for accurate assessment. Comparing these measures against random matrices and pretrained weights reveals that update directions are only slightly below noise, suggesting updates consist of a few strong directions on a long tail. This finding applies across various fine-tuning methods, as instruction data and preference labels do not inherently distinguish alignment. Therefore, rank measures of weight updates necessitate a noise baseline, and alignment claims need a control without alignment content.

Is a Linear Probe Evidence of a Linear Representation?

The linear representation hypothesis suggests pretrained vision models encode generative factors as linearly decodable directions in feature space. A linear probe test, where high accuracy implies a linear representation, is shown to be too permissive. This permissiveness allows high probe accuracy to be consistent with either a true linear world model or a kernel machine where latents reside on a curved manifold. The authors propose three diagnostics—reverse predictivity, spectral concentration, and out-of-distribution generalization—to distinguish these two cases. Validation on vision transformers suggests pretraining produces structure beyond a random kernel but not a true linear world model.

Optimal approximation of smooth functions by ReLU neural networks

The research studies the uniform approximation of the Hölder ball $\mathcal H_1^s([0,1]^D)$ by fully connected ReLU networks. The paper demonstrates that networks with width $O(N)$, depth $O(L)$, and parameter magnitude $O(1)$ achieve an approximation error of order $(N^2L^2\log N)^{-s/D}$. New encoding and decoding mechanisms, exploiting finite-difference bounds, enable this approximation. Empirical risk minimizers over these clipped network classes attain the minimax regression rate $n^{-2s/(2s+D)}$. This work closes the gap regarding information-theoretic efficiency for smooth function approximation by ReLU networks.

Unit-level aggregation breaks coverage in causal foundation models

Unit-level estimates from causal foundation models show coverage degradation when aggregating results over groups of units. This issue arises because the models combine unit-level variances assuming independence, while the posterior uncertainty over the data-generating process makes these errors correlated. Empirically, this correlation leads to combined variances that are too small, and coverage fails significantly when assessing effects averaged over groups. Two neural process models that account for this correlation substantially improve coverage on synthetic tasks and benchmarks.

Information-Geometric Blind Spots of Conformal Test Martingales

Conformal test martingales (CTMs) sequentially test exchangeability using p-values derived from a conformity function. A distribution shift that preserves the push-forward remains invisible to every CTM based on the conformity function. The paper formalizes this blind spot using the $A$-equivalence class and introduces the $A$-cryptic I-projection as the closest element in KL divergence. For the Neyman-Pearson likelihood ratio, the cryptic component vanishes, linking the result to optimal e-value design. The theory is demonstrated empirically on high-dimensional image data.

Adaptive conformal prediction on the Grassmannian

The method introduces a conformal prediction framework for regression with Grassmann-valued responses. Prediction regions are constructed as metric balls on the Grassmann manifold using basis-invariant geometric distances as non-conformity measures. A general recipe for data-adaptive anytime-valid envelopes for iterative algorithms

The paper presents a general recipe for constructing data-adaptive, anytime-valid envelopes for iterative algorithms. It addresses the issue where standard convergence guarantees fix the iteration count, and existing data-adaptive envelopes are case-specific. The framework utilizes a strongly adapted sub-$\psi$ condition and constructs boundaries using methods like continuous and discrete mixtures. This approach allows for the derivation of anytime-valid envelopes that are coupled with algorithmic analysis for various iterative methods, including SGD. The results show that this framework can either recover or improve upon existing envelope constructions for algorithms like SGD.
