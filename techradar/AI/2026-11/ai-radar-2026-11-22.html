A Team of Researchers from Columbia and CertiK Introduce TensorLean for Formal Verification of GPU Kernels

Researchers from Columbia and CertiK introduced TensorLean, a framework for formally verifying GPU kernels at the PTX level using Lean. TensorLean proves that compiled kernels match a tensor-level mathematical specification by checking properties like data races and termination. Testing 149 kernel instances, the framework found 83 correct instances and identified 38 correctness bugs across various projects. The system processes specifications that are significantly smaller than the source code, utilizing techniques like symbolic execution and loop invariant proofs. TensorLean successfully caught a data race in FlashAttention-4 that was not present in extensive prior testing.

Censored vs. Truncated Regression in Python, Explained

Censoring involves recording only a limit, while truncation involves excluding observations above a certain threshold. These two concepts differ in that censoring loses information about an observation, whereas truncation removes the observation entirely. Ordinary Least Squares (OLS) regression estimates are distorted by these data limitations, leading to biased results compared to methods like the Tobit model for censored data and specialized regression for truncated data. Implementing Tobit and truncated regression via maximum likelihood estimation allows for incorporating partial information from observed data. Understanding censoring and truncation is crucial for modern machine learning by guiding the development of censoring-aware models.
