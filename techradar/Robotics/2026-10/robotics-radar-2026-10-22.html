Intramotev to launch autonomous freight rail service in Missouri

Intramotev will deploy its TugVolt autonomous freight railcars on Missouri’s Columbia Terminal Railroad (COLT) as part of a $16.2 million federal grant. This project involves testing autonomous operations on COLT's 21.4-mile line between Centralia and Columbia, Missouri. The grant also covers necessary track and infrastructure upgrades for the railroad. The resulting safety record will serve as a template for other short lines adopting autonomous railcars.

Real-Time Ground Normal Vector Estimation for Spherical Mobile 3D Mapping using LiDAR-Inertial Odometry

Accurate ground plane normal estimation is crucial for odometry in spherical mobile mapping systems due to rapid rotations and limited coverage. Two RANSAC-based methods, single-scan estimation and multi-step validation, are proposed for this task. LiDAR-Inertial Odometry (LIO) estimation, utilizing a global 3D map, is shown to significantly outperform single-scan methods in accuracy and robustness. Integrating these ground normal estimates into the motion model enhances pose estimation, aiding autonomous navigation. This work contributes to improving motion estimation in challenging mobile mapping environments.

arXiv - cs.RO

Warping the Workspace: Expanding Visual Access with Adjustable Reach Mapping for Humanoid Teleoperation

The research explores coupling visual and motor remapping for first-person humanoid teleoperation to expand operator access. It introduces a system that warps the workspace by pairing a panoramic azimuth warp with an inverse upper-limb yaw transform. A working prototype implements Global Zoom (GZ) and Focus+Context (F+C) functionalities for this remapping. Within-subject testing showed that Global Zoom resulted in the highest task completion count, while Focus+Context was preferred by some participants. This study demonstrates that different visual-motor mappings yield varied performance outcomes in humanoid teleoperation.

arXiv - cs.RO

Human-Robot Interaction via Meta-Learning Based Mode Recognition and Adaptive Control

The framework addresses human-robot interaction (HRI) by recognizing interaction modes (active guiding or passive following) without predefined thresholds. A meta-learning neural network is developed to recognize human intention by incorporating force-dependent parameters from the controller. An adaptive meta-learning controller is introduced to compensate for human disturbances and adapt to varying interaction forces online. A multiple-trajectory meta-learning algorithm jointly learns environment representations and force parameters for handling unmodeled dynamics. This approach results in robust mode recognition and adaptive control for safe physical HRI.

arXiv - cs.RO

Learning-Enhanced Observer for Sensorless Task-Null-Space Compliant Control

A novel framework is presented for physical Human-Robot Interaction (pHRI) that integrates a wrench observer with a hybrid pose and force controller. A neural network is used to enhance observer performance by compensating for friction and unmodeled dynamics. Task-null-space decomposition is applied to separate joint velocities and mitigate human disturbance effects on the observer. This method achieves robust wrench estimation and reliable pose/force tracking without requiring force/torque sensors. The approach is effective for pHRI on robotic systems lacking force/torque sensors.

arXiv - cs.RO

VeriCalib: Verifiable Target-Based LiDAR-Camera Calibration

VeriCalib addresses the limitation of traditional LiDAR-camera calibration by formulating it as a verifiable estimation problem. It introduces a two-level extrinsic compensation mechanism to refine the calibration, handling rigid errors at the residual level and rotation/translation at the parameter level. Calibration is assessed using a structured covariance that incorporates uncertainty propagation and known-geometry priors. The method further employs in-view and cross-view checks with thresholds to validate the results under unknown noise. Ultimately, this process yields a calibration state that guides data collection and determines the reliability of the estimated extrinsic parameters.

arXiv - cs.RO

T-WLA: Bridging Slow Vision and Fast Touch

T-WLA introduces a world-language-action architecture to bridge slow visual processing and fast tactile feedback in contact-rich manipulation. It utilizes shared visual memory to guide both action generation and tactile correction. A visual branch integrates visual information and history into memory to condition base action generation. This memory is cached for a tactile editor that predicts residual corrections based on active actions and incoming touch. Evaluation shows T-WLA reduces finger-joint MPJPE by 30% and achieves a 50.0% success rate on real-robot manipulation tasks.

arXiv - cs.RO

Real2Sem2Real: 3D Semantic Augmentations for Robot Learning from a Single Human RGB Demonstration

Real2Sem2Real creates thousands of robot demonstrations from a single human RGB video using 3D semantic augmentations. The method tracks object poses with DINOv3-distilled Gaussian splats to estimate metric depth. It aligns digitally generated object cousins with the demonstration based on semantic information. This process maps the human hand to feasible robot grasps, generating diverse demonstrations for robot learning. Policies trained on this data match or exceed those from teleoperation across various object instances.

arXiv - cs.RO

inr2action: Encoding Robot Episodes as Neural Implicit Representations for Recall and Action

A memory framework is proposed where robot episodes are encoded as separable objects using neural implicit representations. These representations are fitted to episode video from a shared initialization, and the resulting weight delta serves as the memory, maintaining a fixed size regardless of episode length. A learned projector maps this weight delta into token embeddings to condition language models for question answering and command regression. This method allows for scalable streaming memory by decoupling memory cost from the time horizon. Experiments show this approach yields strong performance in language model tasks.

arXiv - cs.RO

Flexible Language-Guided Representation Editing for Adaptive Robot Behavior

Trajectory demonstrations often fail to specify the underlying reasons for robot behavior, leading to inaccurate internal representations. The proposed Flexible Feature Editing Pipeline (FLEX) uses language models to iteratively refine representations of task features through three operations: adding missing features, generalizing existing ones, and masking irrelevant ones. This method addresses limitations of existing representation editing by allowing for more nuanced feature specification. Evaluation on various tasks demonstrated that all three operations are necessary for interactive scenarios. FLEX consistently outperformed other feature editing approaches while maintaining compact and transferable representations.
