Visual Language Models Train Robots to Read Human Emotions

Researchers trained a Vision Language Model (VLM) to help robots read human emotions by incorporating contextual factors beyond just facial expressions. This VLM outperformed traditional AI systems in emotion recognition, achieving an accuracy score of 0.86 compared to 0.77. In a separate test, participants preferred an emotionally adaptive apology from a failing robot over a pre-scripted one. However, trust in the robot was significantly diminished by its physical failure, regardless of the quality of the apology. Ultimately, study results suggest that while emotional cues are valuable, functional competence remains more critical for human co-workers than advanced emotion reading abilities.

ROS Discourse General: LSEP v0.2 — now a buildable ROS 2 reference implementation: typed lsep_msgs + managed lifecycle node, green CI

ROS Discourse General announces v0.2.0 of the LSEP protocol, a runnable reference implementation with typed messages and a managed lifecycle node. Key updates include fixing state machine blind spots for dwell-based de-escalation and adding an input watchdog feature. The repository includes green Continuous Integration that validates temporal behavior via simulation smoke-tests. Authors request feedback on architectural choices such as state representation and modality topic layout. This implementation is noted as a reference build, not certified production safety code, pending real-world robot testing.

ROS Discourse General: Measure serialized topic bandwidth and serialization times using ros_babel_fish_tools

A new tool, `stats`, has been added to `ros_babel_fish` within `ros_babel_fish_tools`. This tool subscribes to any specified ROS topic to gather detailed performance metrics. Specifically, it measures the received message rate and calculates message latency when synchronized clocks are available via a header. Furthermore, it quantifies bandwidth usage based on serialized message size and measures deserialization time. The utility also allows users to assess how message compression affects both bandwidth consumption and overall latency.
