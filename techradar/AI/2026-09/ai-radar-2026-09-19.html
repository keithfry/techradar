Meta-exploration in long-horizon agent discovery is too expensive. Dream-RSI solves it by treating history as a replay simulator.

Dream-RSI addresses the high cost of exploring in long-horizon agent discovery by treating accumulated discovery history as a replay simulator. Instead of costly real-world rollouts, the agent "dreams" through this simulator to receive immediate, low-cost off-policy feedback on exploration strategies. This method allows the agent to evaluate and refine exploration strategies without executing expensive actions in the real environment. Testing across various engineering domains showed significant savings, such as reducing agent calls by 162x in Algorithm Engineering. Although the simulator is bounded by historical exploration, it effectively refines strategies.

We Pinned Our Model Version to Stay Safe. The Provider Deprecated It Anyway.

Pinning a model version prevents silent behavior drift but does not offer immunity from provider deprecation, converting unpredictable changes into scheduled ones. Migrating to a new model requires a costly re-qualification cycle involving re-running evaluations, behavioral diffing, and re-verifying prompts and guardrails. This re-qualification is expensive because moving models invalidates all prior tuning, requiring rigorous testing of prompts, parsers, and cost assumptions. To manage this, teams should treat model versions as pinned dependencies, implement re-qualification gates in the pipeline, and fund a standing, representative evaluation set. Ultimately, understanding and budgeting for this "re-qualification tax" is essential for making informed decisions about model updates.
