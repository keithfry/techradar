Sequential minimal optimization - Wikipedia

Sequential Minimal Optimization (SMO) is an iterative algorithm for solving the quadratic programming problem encountered when training Support Vector Machines (SVMs). Invented by John Platt in 1998, it is widely used for SVM training and is implemented in tools like LIBSVM. SMO works by breaking the main optimization problem into smaller sub-problems, typically involving only two Lagrange multipliers at a time. The algorithm iteratively finds and optimizes pairs of multipliers until convergence is achieved, often using heuristics to speed up the process. SMO is related to other optimization methods and is connected to theorems that allow large problems to be broken down into smaller ones.

Platt scaling - Wikipedia

Platt scaling is a method to transform the outputs of a classification model into a probability distribution over classes, invented by John Platt. It works by fitting a logistic regression model to the classifier's scores, using learned parameters to achieve this transformation. The process involves optimizing parameters using a maximum likelihood method on training data, often using a held-out set for calibration. This technique is particularly effective for models like Support Vector Machines that exhibit distorted probability distributions. Alternative methods, such as isotonic regression or temperature scaling, also exist for probability calibration.
