Irreducible Governance Structure for Autonomous Agent Systems: Fair Allocation, Strategy-Proofness, and Multi-Scale Composition

Allocation is presented as a structural component of autonomous agent governance, not just an auxiliary concern. Allocation mechanisms introduce trade-offs among fairness, efficiency, and strategic resistance when agents compete for resources. These constraints propagate across system dimensions including execution atomicity, state enforcement, behavioral drift, and population allocation. An irreducibility theorem proves that no single governance layer can resolve these dimensions without sacrificing correctness or stability. Consequently, agent governance is reframed as a structural problem concerning how execution access is determined.

MOZAIC: An Audio-Video Deepfake Benchmark for Telling What Is Fake

MOZAIC is a paired benchmark designed to assess audio-video deepfakes by providing four-way labels detailing the real/fake status of both video and audio modalities. It evaluates fakes involving inner-face swapping, video diffusion, and voice conversion, using 137,745 clips from 15,014 source pairs. The benchmark includes tasks for authenticity, manipulation type, identity verification, and explanation. Evaluation shows that multimodal LLMs achieve 35.6% on the primary task, and detectors reach 98.4% accuracy on authenticity. The work also releases the dataset and the MOZAIC-SMALL split.

Conservative Overlap Fuzzy Rough Sets for Incomplete Data

The Conservative Overlap Fuzzy Rough Set (COFRS) model is proposed to address attribute reduction in incomplete information systems by handling missing values differently than standard rough set theory. It defines object similarity based on a weighted overlap of present attributes, penalizing missing values globally. A soft dependency degree is derived from this similarity, and reducts are found using greedy backward elimination in $O(|U|^2 |A|^2)$ time. Experimental results show COFRS yields the smallest reducts on average across various benchmarks with missing data. While COFRS is not superior in predictive accuracy for some classifiers, it offers a gain in compactness.

Beyond Static Charts: Benchmarking Interactive Chart-to-Code Generation for MLLMs

Existing benchmarks for multimodal large language models (MLLMs) focus primarily on static chart-to-code generation, neglecting interactive chart exploration. ChartInt is introduced as a new benchmark specifically designed for interactive chart-to-code generation, including common interaction patterns like hovering and data updates. A preset state snapshot protocol is proposed to enable reproducible evaluation of dynamic interaction behaviors. The framework measures semantic and stylistic consistency during these interactive tasks. Experiments demonstrate that MLLMs perform poorly on interactive tasks compared to static chart generation.

What People Choose Not to Say: A Multimodal Benchmark for Fine-Grained Information Manipulation in Conversations

Existing benchmarks for MLLMs often focus only on coarse-grained emotion or binary truth-deception detection. This research introduces InfoCon, a multimodal benchmark designed to assess fine-grained information manipulation in conversations. It identifies six specific manipulation strategies, including withholding, leakage, fabrication, evasion, and defensive counterclaim. A multi-agent annotation framework is developed to create reliable labels from contextual evidence for this benchmark. The work provides a testbed for evaluating models on nuanced understanding of conversational information manipulation.

arXiv - cs.AI

Antares-Smaug: Adversarial Names, Tokens and Attack Rewrites: Sanitisers Miss Unseen Generalisations

The research investigates how adversarial names, tokens, and attack rewrites affect decision models like Laya, which provide probability outputs based on text and questions. Researchers executed 81 programmatic edits on six Laya models using 566 synthetic items to measure how successfully attackers hijack or lose correct answers. Findings indicate that naming an option steers the model (32%), while character edits cost up to 72% of correct answers in one version. Sanitizers proved ineffective against unseen generalizations, as an attacker could restore success to 84% by selecting the best manipulated strings. Label-free checks focused on option names showed strong performance for sentence attacks (AUROC 0.95).

ContextLure: Exploiting Benign Conversation History for Indirect Prompt Injection

Attackers can exploit benign conversation history to perform indirect prompt injection without altering prior turns. The ContextLure framework allows attackers to silently observe these conversations to extract evidence for injection. To effectively exploit this, the framework selects evidence based on user/system preferences and uses an urgency/priority matrix for constructing malicious requests. Evaluation showed that attackers can leverage this evidence to achieve successful injections in later attacks. Results indicate that attackers can use benign interaction evidence for attacks without poisoning the original conversation.

Learning What vs. Learning How: Decomposing Task and Interface Competence in Agentic Training

Agentic competence is decomposed into task competence, which is the knowledge to solve a task, and interface competence, which is the ability to act on that knowledge through a given harness. Training methods interact differently with these two components, as single-harness training can interfere with interface competence. Harness rehearsal, combining task supervision with interface exposure, yields significantly larger gains than either method alone. Multi-harness distillation aggregates task knowledge, but its effectiveness depends on preserving or improving interface competence during training. Policy reinforcement learning is found to be more robust than distillation for single-harness training while maintaining interface competence across harnesses.

Taxi: Analyzing Agents at (Real) Scale

Taxi is a system designed for debugging, clustering, and monitoring agents efficiently at scale, handling millions of steps. It primarily uses clustering to create a step taxonomy and provides full SQL access for complex querying by engineers and agents. The system employs a hybrid pipeline guided by a coding agent and incorporates Jev-style decision models for probabilistic routing. Taxi features an extensible ecosystem with built-in evaluators and modular design for easy integration. This framework aims to facilitate the analysis of large-scale agent behavior.

SpatialCraft: Evolving Procedural Intelligence from Experience and Skills for Spatial Reasoning Agents

Spatial reasoning agents often struggle with orchestrating external tools for spatial tasks. SpatialCraft is a self-evolving framework that allows frozen agents to improve orchestration based on their interaction history. It maintains two forms of external knowledge: Experiences, which are condition-action tactics, and Skills, which are multi-step procedures. Experiences are refined using a Contrastive Utility Score to isolate their true impact. SpatialCraft demonstrates superior accuracy across spatial benchmarks by learning to manage spatial tools from experience.
