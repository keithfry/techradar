Navalia: Advancing Cowork Agents through Verifiable Task Synthesis and Long-Horizon Post-Training

Navalia is a framework designed to advance Cowork Agents by incorporating verifiable task synthesis and long-horizon post-training. It uses corporate financial reports to semantically select evidence and construct computation chains for generating analytical tasks with traceable dependencies. Independent LLM review and programmatic checks are employed to verify evidence consistency and answer accuracy. These verified tasks are then used for trajectory collection, supervised fine-tuning, and reinforcement learning to enhance long-horizon execution. The method consistently improves evidence integration, tool use, and task execution across various benchmarks.

Pareto-Optimal RTL Code Generation via Multi-Objective Reinforcement Learning with Large Language Models

The research proposes a method using multi-objective reinforcement learning with Large Language Models for Pareto-optimal Register-Transfer Level (RTL) code generation. Existing methods struggle to generate diverse solutions across multiple trade-offs like Power, Performance, and Area simultaneously. The proposed method trains a generation pipeline to optimize the coverage improvement of the entire Pareto solution set. Evaluations show the method significantly improves Hypervolume and circuit diversity compared to baseline methods.

Fix, Not Just Resample: Bounded Compiler-Guided Repair in Lean 4

Automated theorem provers in Lean often discard valuable error information during failed steps when using pure sampling. This work introduces a bounded, online repair module that samples tactics and repairs failed tactics based on the compiler's error messages. A pretrained repair model is used to fix individual rejected steps in place, rather than discarding them. This method improves the solve rate by up to 32% compared to sampling-only baselines. When Planning Problems Become Hard for LLMs: Separating Structural Complexity from Semantic Interpretability

Large language models struggle with classical planning, but current benchmarks do not effectively separate structural complexity from semantic interpretability. The zero-training delete-relaxation heuristic $h_{\mathrm{add}}$ significantly outperforms other learned predictors for estimating structural difficulty. Renaming predicates demonstrates that LLM planning success degrades as the semantic complexity increases, while conditioning information predicts difficulty better than trained models. Hybrid planning relies more on calibrating to LLM outcomes than on structural scores. Therefore, improving hybrid planning should focus on modeling LLM behavior sensitive to predicate semantics.

Beyond Policy Discrepancy: Capability-Aware Multi-Teacher On-Policy Distillation

Capability-Aware Multi-Teacher On-Policy Distillation (CA-MOPD) addresses challenges in multi-teacher on-policy distillation by incorporating student capabilities into supervision allocation. It merges reinforcement-learning specialists into a strong student initialization before guiding distillation. CA-MOPD uses verifier-estimated teacher-student capability gaps to dynamically adjust domain-level distillation strength. Supervision is reduced when capability gaps close and increased when student capability regresses, while retaining dense token-level guidance. Across six benchmarks, CA-MOPD outperformed other methods, showing significant gains over naive MOPD and Open-MOPD.

One class fails to length-generalize, while the other perfectly length-generalizes despite fixed-length training. Latent world models allow agents to plan in latent space by minimizing the $\ell_2$ distance to a goal latent. Quadratic Sample Complexity for Strictly Replicable Realizable Learning with Unknown Marginals

The paper determines the sample-complexity exponent for strict replicability when the realizable distribution and its marginal are unknown. It establishes that two independent samples and one shared seed must yield identical functions for strict replicability. For specific parameters, the worst-case sample complexity is shown to be $\Theta((\log M)^2)$ without iterated logarithms. Furthermore, the work provides a matching characterization $\Theta(d^2/(\varepsilon\rho^2)+\varepsilon^{-1}\log(1/\delta))$ for the full Boolean class $P_d$ using a proper Poissonized ball-sampling algorithm. The results involve lower bounds using square-root probabilities and volumetric packing, and an explicit Gibbs upper bound.

Uncertainty quantification in time series forecasting is challenging due to temporal dependence and distributional shifts. Dynamic Dual-feedback Conformal Inference (DDCI) is proposed to address this by incorporating a dual-feedback mechanism. This mechanism uses both actual feedback from true observations and estimated feedback from conformal inference to adjust prediction intervals. Actual feedback drives the primary interval adjustment, while estimated feedback moderates expansions or contractions using empirical thresholds. DDCI results in more stable and narrower prediction intervals while maintaining practical coverage.

The study investigates using Gaussian kernel approximation and regularized logistic classification on smooth, connected, compact, embedded manifolds. The paper studies the communication complexity of representing data that allows for evaluation with a family of functions. What Moved the Alarm Score? Causal Attribution with Exact Computation and Scarce-Incident Estimation

Alarms in industrial systems require explanations tracing changes in the data-generating process to the alarm score, despite scarce incident data. The paper formulates the alarm-score change as a Shapley game over hybrid structural causal model (SCM) states to attribute propagation. It distinguishes between changes in structural functions and exogenous laws for a finer-grained report of influence. Exact Shapley vectors are computed in polynomial time for linear SCMs and quadratic scores using first- and second-moment recursion. The method adapts a reference SCM to estimate these changes from limited data, providing attribution-error bounds.
