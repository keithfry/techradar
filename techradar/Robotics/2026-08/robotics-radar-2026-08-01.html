ROS Discourse General: VectorField Planner: 7 µs global path queries with strict optimality — REST API for occupancy grids, Nav2 plugin on roadmap

A free API tier has been opened for a global planning engine aimed at warehouse and fleet deployments. It solves a field for a goal, such as a charging station or pick station, and returns a strictly optimal path in microseconds for any start cell query, without re-searching the map. The system measures 1M-cell 3D warehouses maps with peak memory of 5MB and can handle 10,000 simultaneous queries. A native Nav2 global-planner plugin is on the roadmap.
